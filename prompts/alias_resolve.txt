## 归并规则

### 必须归并的情况
1. **全称与简称**：如"陈二蛋"和"二蛋"是同一人
2. **本名与字/号/外号**：如"诸葛亮"和"孔明"，"宋江"和"及时雨"
3. **本名与身份称呼**：如"陈二蛋"和"我"（第一人称），"王婆"和"王稳婆"
4. **身份相同且出场不重叠**：同一身份在同一本书中通常是同一人
5. **alias 列表包含对方**：如果 A 的 alias 中有 B，B 的 alias 中有 A，几乎可确定是同一人
6. **本名与后期称号**：如"陈二蛋"和"陈老魔"、"黑手双城"若为同主角在不同时期
7. **圣经情节线索**：如果 bible 中明确描述了同一人物的不同成长阶段名称，请据此归并
8. **重叠仅限1章**：如果两个角色仅在同一章出现1-2次且无互动，可能是叙事视角切换（如成年回忆 vs 童年本名），请结合圣经判断

### 拓展规则：读者提取的碎片角色名
由于自动提取工具（reader）可能将同一人物的不同称谓提取为独立角色，特别需要注意：
- **他爹派生形态**：如果存在"X他爹"和"我爹"、"老陈"等，极可能是同一人——
  例："陈二蛋他爹"= "我爹" = "老陈" = "陈知礼"
- **他娘/我娘/母亲**派生形态同理："我娘" = "母亲" = "老陈之妻"
- **动物别名**：如果角色 A 在章节 N 被称为"小猴子"，在章节 N+1 被称为"胖妞"，
  且"小猴子"在章节 N+1 后消失——这是同一动物被收养后的改名

### 外貌比对规则（重要判断依据）
每个角色附带了原文中的外貌描写片段。请仔细比对：
1. **外貌高度相似**：如果两个角色的外貌片段描述了相似的体型、穿着、发型等特征，极可能是一人
2. **外貌互补**：如果 A 的外貌片段描述上半身，B 描述下半身，且章节不重叠，可能是一人
3. **外貌矛盾**：如果两个角色外貌明显不同（如一男一女、一老一少），不应合并
4. **外貌缺失**：如果一个角色有外貌片段而另一个没有，结合其他线索判断

### 关系网络规则
每个角色附带了与其他角色的关系描述。请利用关系网交叉验证：
1. **关系交叉**：如果 A 认识 B，B 认识 C，且 A 和 C 出场不重叠，A 和 C 可能是同一人
2. **关系矛盾**：如果 A 与 B 是"夫妻"，但 A 与 C 也是"夫妻"，且 B≠C，则 A 可能被拆分成了多人
3. **关系孤立**：如果一个角色与其他角色完全没有关系链接，可能是碎片角色

### 性别一致性规则
1. **性别冲突检测**：如果两个待合并角色的性别不同（如一男一女），必须非常谨慎
   - 先检查外貌片段中是否有明确的性别指示词（如"他""她""先生""女士"）
   - 再检查圣经情节中是否有性别描述
   - 如果仍然无法确定，不要合并，标记为"需人工确认"
2. **性别缺失**：如果角色性别为"未明确"，参考外貌片段中的代词和称谓推断

### 无需归并的情况
- 确实属于不同个人的独立角色
- 动物与人类（除非别名明确指向同一动物）
- 绰号指向不同个体的（如"老张"和"张师傅"可能是不同人）
- 性别明显不同且无证据表明是同一人

### 重要原则
- **当不确定时，保守处理**
- 保留所有角色，只合并明显是同一人的
- 每个合并组中的第一个名字作为规范名（canonical name）
- **高置信度合并**（外貌+性别+关系全匹配）：直接归并
- **中置信度合并**（部分匹配，如仅章节互补或仅名字相似）：归并但标注"需确认"
