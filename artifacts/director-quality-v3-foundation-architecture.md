# Director Quality V3 Foundation — Architecture

FactSnapshot → Qualified ScriptIR → DirectorTreatment → SceneBlocking → SceneDirectingStrategy → Draft ShotPlan → Layer 1/Layer 2 QA → optional Director Critic → Approved ShotPlan → existing Scene Repair → Tail Repair → Production.

Draft topology is mutable; Approved topology is frozen. Strategy is semantic and never emits canonical patch paths.
