## 轻微改进建议

1. `问题清单` 的问题卡片虽然可点击跳转，但当前没有显式的 `定位 / 查看 / 跳转` 按钮文案。建议补一个明显操作入口，降低用户认知成本。
2. `审片备注` 字段与正文、提示词区域都使用 textarea，自动化和人工快速扫视时容易误填。建议给审片备注增加 placeholder，例如“填写审片修改意见，会同步进入问题清单”。
3. `npm run build` 的 chunk size warning 后续可以通过动态 import 或手动拆包处理，但不影响本阶段功能验收。
