# 2026-07-21 镜头工作台场景/道具正式变体回填验收记录

## 验收目标

验证镜头工作台与 prompt compile context 已经接入资产中心的正式变体契约，不再把单版本场景、单版本道具一律误显示为“场景变体 / 道具变体”。

## 本轮实现

### 后端

- `api/server.py`
  - `prompt compile context` 中的场景、道具绑定改为复用正式变体元数据：
    - `variant_scope`
    - `scope_label`
    - `stage_name`
  - 不再为单版本场景/道具硬编码 `scene_variant / prop_variant`
  - 新增历史 `prompt_compile_context` 契约漂移检测
  - 当旧缓存与当前正式契约不一致时，自动重建并回填

### 前端

- `web/src/components/ProductWorkspaceStoryboardSection.tsx`
  - 镜头工作台的场景绑定、道具绑定不再默认强行套用“场景变体 / 道具变体”
  - 当正式变体字段为空时，回退展示为“当前版本”
- `web/src/prototyping/sceneComposerData.ts`
  - 为 `prompt_compile_context.asset_bindings.props` 补齐：
    - `variant_scope`
    - `scope_label`
    - `stage_name`
