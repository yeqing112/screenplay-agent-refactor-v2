# 2026-07-29 资产中心承接后首个动作验收记录

## 验收范围

- 模块：正式产品工作台 -> 资产中心
- 目标：把创作画布进入资产中心后的承接逻辑收口为“承接后的首个动作 + 立即继续”
- 验收项目：`三个和尚`

## 本次调整

1. 统一资产中心承接卡的按钮语义：
   - 从直接显示动作名改为统一显示 `立即继续`
   - 动作名保留在卡片正文内，和镜头工作台、QA、交付、任务中心保持一致

2. 修复承接冲突：
   - 当 `canvasHandoff` 存在时，资产详情区优先显示创作画布承接卡
   - 不再同时显示旧的任务恢复提示，避免双来源上下文抢占注意力

## 自动化验收

- 通过：`cd web && npm run test -- ProductWorkspaceAssetsSection ProductWorkspaceAssetsSection.canvasHandoff`
- 通过：`cd web && npm run build`

## 真浏览器验收

### 路径

`三个和尚 -> 正式产品工作台 -> 创作画布 Beta -> 寺庙后院水房 -> 打开对应模块`

### 结果

1. 成功进入 `资产中心`
2. 顶部横幅正确显示：
   - `来自创作画布的下一步`
   - `当前承接：第 1 集 / 镜头 1 / 寺庙后院水房`
3. 资产详情区正确显示：
   - `创作画布承接中`
   - `承接后的首个动作`
   - `生成当前版本参考图`
   - `立即继续`
4. 旧的 `已从任务中心恢复到当前资产` 提示不再和创作画布承接同时出现
5. 当前动作与真实资产状态一致：
   - 该资产无可预览参考图
   - 页面正确推荐先补齐当前版本参考图

## 验收结论

本轮验收通过。

资产中心现在已经和镜头工作台、QA、交付、任务中心形成统一的承接体验：用户进入模块后，不只知道“我是从哪里来的”，也能立刻知道“现在先做什么”，并且不会再被多条来源提示同时干扰。
