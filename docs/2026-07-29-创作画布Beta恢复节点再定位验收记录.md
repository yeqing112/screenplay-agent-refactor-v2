# 2026-07-29 创作画布 Beta 恢复节点再定位验收记录

## 本轮目标

继续补强 `任务中心 -> 创作画布 Beta` 的恢复链路。

在上一轮里，画布已经能显示 `恢复上下文`，但如果用户在画布内改过搜索词、筛选条件或浏览过其他节点，缺少一个显式动作把他带回这次恢复链路的目标节点。

本轮目标就是补上这个动作。

## 本轮实现

涉及文件：

- `web/src/components/productWorkspaceCanvasBeta.ts`
- `web/src/components/ProductWorkspaceCanvasBetaSection.tsx`
- `web/src/components/productWorkspaceCanvasBeta.test.ts`

关键改动：

1. 新增 `shouldShowCanvasNavigationRefocusAction`
   - 用于判断当前是否应该显示“定位恢复节点”

2. 在 `创作画布 Beta` 的 `恢复上下文` 横幅中新增按钮：
   - `定位恢复节点`

3. 点击 `定位恢复节点` 时，会主动恢复这次恢复入口的默认视图状态：
   - 恢复目标分集
   - 清空搜索词
   - 重置状态筛选
   - 展开被折叠的资产分组
   - 将选中节点重新落回目标节点

## 真浏览器验收

验收环境：

- 前端：`http://127.0.0.1:5175`
- 项目：`三个和尚`

验收路径：

`三个和尚 -> 任务中心 -> 首帧结果回收 -> 在创作画布查看`

验收步骤：

1. 进入 `创作画布 Beta`
2. 等恢复上下文与目标节点稳定出现
3. 在搜索框中输入 `和尚丙`
4. 观察页面仍显示 `定位恢复节点`
5. 点击 `定位恢复节点`

验收结果：

```json
{
  "beforeRefocus": {
    "hasShot3Detail": true,
    "hasRefocusButton": true
  },
  "afterRefocus": {
    "restoredShot3Detail": true,
    "searchCleared": true,
    "stillHasRecoveryBanner": true
  }
}
```

结论说明：

1. 即使用户在画布中改变搜索范围，恢复横幅仍然保留
2. `定位恢复节点` 可以把用户重新带回当前恢复链路的目标镜头
3. 搜索词会被自动清空，避免旧筛选继续干扰恢复操作
4. `恢复上下文` 不会因为重新定位而丢失

## 结论

- 通过

这一步的意义在于：

1. 恢复链路不再只是“一次性进入画布”
2. 用户在画布内迷失后，依然能快速回到当前恢复目标
3. 这让 `创作画布 Beta` 更接近 LibTV 式“可持续操作的创作恢复面板”，而不是仅仅支持一次跳转的浏览页
