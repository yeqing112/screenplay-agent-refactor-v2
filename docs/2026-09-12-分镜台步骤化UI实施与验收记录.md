# 分镜台步骤化 UI 实施与验收记录

日期：2026-09-12  
范围：正式工作台 → 镜头工作台  
目标：让普通创作者按生产顺序理解并完成单镜头工作，不要求先理解 Prompt、API 或内部状态码。

## 本次实施

镜头详情改为六个步骤选项卡：

1. 看懂镜头：当前镜头状态、唯一主动作、导演分镜语言和基础决策。
2. 准备素材：人物/场景/道具摘要、参考图、手动上传和当前可用输入。
3. 生成分镜图：结构化分镜图提示词与分镜图生产动作。
4. 生成视频：机器提示词、实际多参考输入、视频提交与生成动作。
5. 检查结果：连续性、验收记录和当前媒体结果。
6. 更多工具：诊断、修复、Prompt 版本/回滚、编译上下文和高级导出。

首层仍保留当前镜头、生产状态、唯一主动作和上游放行状态。步骤完成标记只从已有事实计算：Prompt 是否编译、是否有锁定参考资产、是否采纳分镜图/视频、是否有验收记录；不依赖书号、镜头号或关键词。

## 可访问性与承接

- 导航使用标准 `tablist`、`tab`、`tabpanel` 语义。
- 正式工作台左侧分区导航为当前页面项提供 `aria-current="page"`，所有导航按钮提供统一 `focus-visible` 焦点环，便于键盘和读屏用户确认当前位置。
- 每个标签包含 `aria-selected`、`aria-controls` 和稳定的面板关联。
- 支持 `ArrowLeft/ArrowRight`、`ArrowUp/ArrowDown`、`Home`、`End` 键切换步骤，非当前标签从 Tab 顺序中移除，避免键盘重复经过隐藏步骤。
- 切换镜头后回到“看懂镜头”，避免误带上一个镜头的生产上下文。
- 任务中心和创作画布可使用 `initialStoryboardStep` 将用户直接带到对应步骤；当前不改变既有任务、权限或外部调用确认。
