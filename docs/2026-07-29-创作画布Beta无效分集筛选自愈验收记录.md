# 2026-07-29 创作画布 Beta 无效分集筛选自愈验收记录

## 本轮目标

验证 `创作画布 Beta` 在恢复链路中遇到异常前端状态时，是否还能保持稳定，不会误掉进“无数据”空态。

这次重点验证的问题是：

- 当前分集筛选值一旦失真，画布是否会错误丢失恢复上下文
- 是否会把真实恢复场景误判成“当前项目还没有可映射的数据”

## 发现的问题

在真浏览器里，进入路径：

`三个和尚 -> 任务中心 -> 首帧结果回收 -> 在创作画布查看`

随后通过脚本把 `当前分集` 的 `select.value` 强行写成一个不存在的值 `2`。

修复前表现：

1. DOM 中的选择值失效
2. 画布图谱被错误过滤为空
3. 页面直接落入泛化空态文案：
   - `当前项目还没有可映射的数据`

这说明恢复链路对异常筛选状态不够鲁棒。

## 修复方案

涉及文件：

- `D:\Work\Project\screenplay-agent-refactor-v2\web\src\components\productWorkspaceCanvasBeta.ts`
- `D:\Work\Project\screenplay-agent-refactor-v2\web\src\components\ProductWorkspaceCanvasBetaSection.tsx`
- `D:\Work\Project\screenplay-agent-refactor-v2\web\src\components\productWorkspaceCanvasBeta.test.ts`

新增能力：

1. 新增 `resolveCanvasEpisodeSelection`
2. 对 `selectedEpisode` 做有效性归一化：
   - 当前值合法则保留
   - 当前值非法且恢复上下文里的 episode 合法，则回退到恢复上下文 episode
   - 否则回退到可用集数的第一项
   - 若没有任何可用集数，则退回 `all`
3. 在画布组件中新增自愈 effect，保证异常筛选值不会长期污染画布态
