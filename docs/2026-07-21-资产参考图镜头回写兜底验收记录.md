# 2026-07-21 资产参考图镜头回写兜底验收记录

## 验收目标

补强“资产中心生成参考图 -> 回写分镜引用”的兜底链路，避免出现以下问题：

- 资产已经识别出影响镜头
- 但资产本身还没有保存 `shot_ids`
- 参考图生成后无法稳定同步回分镜

## 本轮改动

### 1. 前端补图目标镜头选择补强

文件：

- `web/src/components/productWorkspaceAssetActions.ts`
- `web/src/components/ProductWorkspace.tsx`

改动内容：

- 资产补图时不再只依赖 `selectedAsset.shotIds`
- 如果资产还没有保存显式绑定，但系统已经识别出 `impactShots`
- 则优先使用这些真实影响镜头作为本次参考图任务的目标镜头

### 2. 服务端回写分镜时新增 `shotId` 兜底

文件：

- `api/server.py`

改动内容：

- 资产参考图写入分镜时，把 `meta_info.shotId` 透传到 storyboard reference metadata
- 若常规资产/结构化/文本匹配没有找到目标镜头，则允许使用该 `shotId` 作为回写兜底

### 3. 资产中心列表文案修正

文件：

- `web/src/components/ProductWorkspaceAssetsSection.tsx`

改动内容：

- 当系统已经识别出影响镜头，但资产还没保存显式绑定时
- 列表中不再错误显示 `待同步绑定 0`
- 而是显示真实待同步数量，例如 `待同步绑定 6`

## 新增/更新测试

### 前端

- `web/src/components/productWorkspaceAssetActions.test.ts`
- `web/src/components/ProductWorkspaceAssetsSection.test.tsx`

覆盖点：

1. 有显式 `shotIds` 时优先使用显式绑定
2. 无显式 `shotIds` 时回退到 `impactShots`
3. 无显式绑定也无影响镜头时，才回退到默认镜头
4. 资产列表正确显示待同步绑定数量

### 后端

- `tests/test_visual_asset_library.py`

新增覆盖点：

1. 当资产本身没有已绑定镜头时
2. 只要创建参考图记录时带了 `metaInfo.shotId`
3. 服务端也能成功把参考图同步进对应镜头的 storyboard reference
