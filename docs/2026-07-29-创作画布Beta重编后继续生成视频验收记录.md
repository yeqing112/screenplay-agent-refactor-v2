# 2026-07-29 创作画布 Beta 重编后继续生成视频验收记录

## 验收目标

验证创作画布 Beta 已补齐 L2 的连续动作链路：

- 用户可在画布中直接点击 `重编后继续生成视频`
- 前端先触发提示词重编译
- 重编成功后自动继续触发视频生成
- 视频生成请求显式带上重编链路元数据
- 页面同时保留提示词与视频的恢复入口

## 本次实现

涉及文件：

- `web/src/components/ProductWorkspaceCanvasBetaSection.tsx`

新增能力：

1. `handleCompilePrompts(...)` 现在返回结构化结果，供后续连续动作使用
2. 新增 `handleRecompileThenGenerateVideo()`
3. 复用正式分镜工作台的链路透传字段：
   - `generationChain: recompile_then_video`
   - `triggeredByPromptRecompile: true`
   - `promptRecompileReason`
   - `promptRecompileTaskId`
   - `promptRecompileVersion`
4. 在创作画布右侧分镜执行卡新增 `重编后继续生成视频`

## 真浏览器验收

验收地址：

- 前端：[http://127.0.0.1:5175](http://127.0.0.1:5175)

验收方式：

- 使用真实浏览器打开 `三个和尚 -> 正式工作台 -> 创作画布 Beta`
- 选中存在已采纳首帧的镜头 `镜头 1`
- 对编译接口、视频接口与任务状态接口做浏览器侧网络拦截，避免实际触发付费模型

验收步骤：

1. 打开 `三个和尚`
2. 进入 `正式工作台 -> 创作画布 Beta`
3. 点击 `镜头 1`
4. 确认右侧出现 `重编后继续生成视频`
5. 点击 `重编后继续生成视频`
6. 观察请求顺序、请求体与页面文案

浏览器观测结果：

- 页面存在 `重编后继续生成视频`
- 请求顺序为：
  1. `compile-prompts/async`
  2. `storyboard-prompt-compile-tasks/{taskId}`
  3. `generate-video`
  4. `api/prototyping/tasks/{taskId}`
- 提示词重编请求体为：

```json
{
  "compileReason": "manual-recompile-before-video",
  "force": false
}
```

- 视频生成请求体为：

```json
{
  "compileIfMissing": true,
  "firstFrameAssetId": "image-87712c282a",
  "referenceAssetIds": ["ref-8", "ref-42", "ref-41", "ref-34", "ref-49"],
  "generationChain": "recompile_then_video",
  "triggeredByPromptRecompile": true,
  "promptRecompileReason": "manual-recompile-before-video",
  "promptRecompileTaskId": "canvas-prompt-002",
  "promptRecompileVersion": 13
}
```

- 页面出现成功文案：
  - `已重新编译到 v13。`
  - `视频已生成并写回镜头。`

## 验收结论

创作画布 Beta 已从“单动作可执行”继续推进到“连续动作可执行”：

- 已复用正式分镜工作台的链路透传规范
- 已在真浏览器中验证请求顺序与请求体正确
