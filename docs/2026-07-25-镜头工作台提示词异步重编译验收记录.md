# 2026-07-25 镜头工作台提示词异步重编译验收记录

## 本轮目标

验证镜头工作台里的“重新编译提示词”是否已经从同步阻塞按钮，改为可恢复、可感知状态的异步重编译链路。

## 本轮修复

1. 后端新增并打通异步提示词重编译任务接口
   - `POST /api/books/{book_id}/storyboard/{episode}/{shot_id}/compile-prompts/async`
   - `GET /api/storyboard-prompt-compile-tasks/{task_id}`
2. 前端镜头工作台改为：
   - 点击后立即提交异步任务
   - 显示“已提交重编译任务，正在后台执行。任务 ID：...”
   - 轮询任务状态
   - 完成后自动刷新提示词版本与镜头数据
3. 修复一个真实页面入口问题：
   - 之前只有 `visual_fact_target_coverage` 失败时才显示“重新编译提示词”
   - 现已补充 `authority_prompt_inheritance` 失败场景，避免真实镜头已有编译问题但入口消失
4. 修复一个后端伪异步问题：
   - 原实现使用 `BackgroundTasks`
   - 在当前运行形态下响应未能即时返回，前端会长期卡在“正在提交”
   - 现改为后台线程内 `asyncio.run(...)`，真正脱离请求生命周期

## 遗留建议

1. 当前“正在提交当前镜头提示词重编译任务，通常需要 30-60 秒。”会很快切换到任务号提示，这是正确行为，但仍可再优化成更明显的双阶段文案。
2. 下一步可把这类提示词重编译任务进一步纳入任务中心，支持跨页面恢复与回看。
3. `ProductionMode` 与批量 `batch-compile-prompts` 目前仍走同步接口，建议下一阶段统一切到异步任务模型。
