# 2026-07-29 创作画布单镜头推荐下一步验收记录

## 目标

把 `创作画布 Beta` 继续从“能点很多执行按钮”的关系图，推进成“能明确告诉用户当前应该先做什么”的创作工作面。

## 本轮实现

- 在 `ProductWorkspaceCanvasBetaSection.tsx` 中新增 `buildCanvasShotPrimaryActionPlan(...)`。
- 面向普通镜头态和恢复态，统一给出单镜头主动作建议：
  - 有待回收视频任务 -> `继续回收视频任务`
  - 有待回收首帧任务 -> `继续回收首帧任务`
  - 有待回收提示词任务 -> `继续回收提示词任务`
  - 无稳定提示词 -> `先重编译提示词`
  - 有提示词但无已采纳首帧 -> `先生成首帧`
  - 有已采纳首帧但无视频 -> `继续生成视频`
  - 首帧与视频链路均已有结果 -> `前往镜头工作台确认结果`
- 在画布右侧 `单镜头执行` 区域新增 `推荐下一步` 卡片，并把主按钮直接接到真实动作或真实任务中心路由。
