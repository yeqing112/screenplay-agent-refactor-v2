# 2026-07-21 分镜诊断去重与人物状态细化验收记录

## 本轮目标

继续沿提示词质量治理主线推进，解决两个更细的生产问题：

1. `visual_fact_target_coverage` 与 `authority_prompt_inheritance` 同时失败时，容易对同一资产重复报警
2. `character_variant_state` 虽然能报人物当前状态缺失，但过去只给角色名，不够利于自动修复

## 本轮实现

### 1. 诊断分层与去重

文件：

- `api/server.py`
- `tests/test_storyboard_prompt_authority_diagnostics.py`

处理：

- 当某个资产已经被 `visual_fact_target_coverage` 判定为“首轮视觉事实覆盖不足”
- `authority_prompt_inheritance` 不再对同一资产重复报失败

结果：

- `visual_fact_target_coverage` 负责表达“首轮编译合同层”的事实缺失
- `authority_prompt_inheritance` 退回到更补位的角色，不再和前者对同一问题重复轰炸

### 2. 人物当前状态告警细化

文件：

- `api/server.py`
- `tests/test_storyboard_prompt_authority_diagnostics.py`
- `tests/test_makeup_variant_resolution.py`

处理：

- `character_variant_state` 的 `details` 从单纯的角色名
- 升级为：
  - `角色名：补入 关键词A / 关键词B / 关键词C`

这让：

- 人工排查更直接
- 自动修复上下文也能继续吃到更具体的状态缺失事实
