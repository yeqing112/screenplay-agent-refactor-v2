# 2026-07-21 资产中心场景/道具正式变体语义验收记录

## 验收目标

验证资产中心里的场景、道具“多版本”语义已经收敛为正式数据契约，而不是继续依赖前端猜测：

1. 只有同名同族资产真实存在多条记录时，才标记为正式变体。
2. 场景使用 `scene_variant`，道具使用 `prop_variant`。
3. `visual-assets` 与 `pipeline outputs` 两条接口链路输出一致。
4. 真实项目页面中的版本统计不被误伤。

## 本轮实现

### 后端

- 在 `api/server.py` 中为场景、道具补齐显式字段：
  - `variant_scope`
  - `scope_label`
  - `stage_name`
- 正式变体判定规则：
  - 仅当同一本书中存在多个同名场景记录时，输出 `scene_variant`
  - 仅当同一本书中存在多个同名道具记录时，输出 `prop_variant`
- `visual-assets` 与 `/api/pipeline/book/{book_id}/outputs` 已统一复用相同序列化逻辑。

### 前端

- `web/src/prototyping/sceneComposerData.ts` 为场景、道具输出类型补齐：
  - `variant_scope`
  - `scope_label`
  - `stage_name`
- `web/src/components/productWorkspaceAssets.ts` 改为：
  - 优先消费后端显式字段
  - 后端缺失时才回退到本地推断

### 回归测试

- `tests/test_visual_asset_library.py`
  - 新增单记录默认不标记正式变体断言
  - 新增多同名场景/道具记录的接口往返断言
