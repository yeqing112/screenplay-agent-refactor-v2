# 2026-08-04 模型管理中文化与默认代理修正验收记录

## 1. 背景

在继续推进正式工作台高频模块时，模型管理暴露出两个影响真实验收与产品完成度的问题：

1. 前端默认代理目标仍可能回退到 `http://localhost:8765`
2. `模型管理` 弹窗中仍存在较多用户可见英文文案，和正式工作台整体中文口径不一致

本次目标：

- 从源头修正前端默认代理目标
- 把模型管理主列表与编辑面板的高频用户文案统一为中文
- 完成自动化回归与真浏览器复验

## 2. 本次改动

- [vite.config.ts](D:/Work/Project/screenplay-agent-refactor-v2/web/vite.config.ts)
