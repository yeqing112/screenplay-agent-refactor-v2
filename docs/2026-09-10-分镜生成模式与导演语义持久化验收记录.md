# 2026-09-10 分镜生成模式与导演语义持久化验收记录

## 目标

把正式分镜生成明确收敛到导演 LLM 主路径，并将镜头导演语义从易丢失的派生 JSON 提升为可持久化、可回放、可导出的正式字段。

## 实施内容

### 生成模式

- `POST /api/pipeline/storyboard` 默认 `generation_mode=director_llm`。
- `deterministic_safe` 只在请求中显式指定时启用。
- `forceLlm=true/false` 保留为兼容别名，但会被归一化为上述两种模式。
- 任务状态保存最终归一化模式，节点执行器采用同一校验规则。
- 正式工作台显式发送 `generation_mode=director_llm`，避免前端和后端默认值漂移。

### 导演语义字段

新增并贯通：

| 字段 | 含义 |
| --- | --- |
| `camera_speed` | 镜头运动速度（slow / medium / fast 等模型可读值） |
| `shot_purpose` | 当前镜头叙事目的，如 establishing / action / reveal / emotion |
| `emotion_arc` | 当前镜头情绪起点、终点和强度 |

字段链路为：`LLM/fallback → normalize → StoryboardShot → API → 刷新 → Shot IR/Prompt Compiler → WebUI/API 导出`。拆镜时复制父镜头语义；结构编辑时支持显式人工修改。

### 数据迁移

Alembic revision：`d7e8f9a0b1c2`（基于 `c6f7a8b9c0d1`）。迁移仅在字段缺失时加列，并从旧 `meta_info.structured_shot` 回填非默认值；不会删除旧 JSON 或覆盖已存在的正式字段。
