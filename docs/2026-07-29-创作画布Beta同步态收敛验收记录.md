# 2026-07-29 创作画布 Beta 同步态收敛验收记录

## 本轮目标

修复 `任务中心 -> 创作画布 Beta` 切换过程中短暂闪现“空画布文案”的问题。

目标不是改变最终链路，而是让用户在跨工作面恢复时，先看到“正在同步真实项目数据”，而不是误以为当前项目没有可映射数据。

## 本轮实现

涉及文件：

- `web/src/components/productWorkspaceSectionContracts.ts`
- `web/src/components/productWorkspaceSectionBundlesController.ts`
- `web/src/components/ProductWorkspaceSectionContent.tsx`
- `web/src/components/productWorkspaceCanvasBeta.ts`
- `web/src/components/ProductWorkspaceCanvasBetaSection.tsx`
- `web/src/components/productWorkspaceCanvasBeta.test.ts`

关键改动：

1. 为 `CanvasBundle` 增加 `isProjectDataLoading`
2. 将正式产品工作区的项目数据加载状态透传到 `创作画布 Beta`
3. 在画布侧新增 `shouldShowCanvasSyncingState`
4. 当 `graph.nodes.length === 0 && isProjectDataLoading === true` 时：
   - 不再显示“当前项目还没有可映射的数据”
   - 改为显示“正在同步真实项目数据”
   - 若本次进入带有恢复上下文，则同步显示当前恢复摘要

## 真浏览器验收

验收环境：

- 前端：`http://127.0.0.1:5175`
- 项目：`三个和尚`

验收路径：

`三个和尚 -> 任务中心 -> 首帧结果回收 -> 在创作画布查看`

验收结果：

1. 刚进入 `创作画布 Beta` 时，早期状态显示：
   - `正在同步项目数据` 或 `正在同步真实项目数据`
2. 不再出现错误空态文案：
   - `当前项目还没有可映射的数据`
3. 等项目数据同步完成后，页面稳定显示：
   - `恢复上下文`
   - `回任务中心`
   - `前往镜头工作台`
