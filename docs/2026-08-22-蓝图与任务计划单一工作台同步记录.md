# 2026-08-22 蓝图与任务计划单一工作台同步记录

## 背景

前端已经完成单一正式工作台收敛：旧版生产、创作沙盘、高级编排、产品原型 Demo 不再作为用户入口或新增功能承载面。正式工作台已经补齐 QA 人工修复、diff 预览、应用修复、脚本版本回滚、镜头提示词锁定和验收记录提交。

同时，项目新增 `npm run e2e:business`，用真实浏览器跑通正式工作台业务流：从项目列表进入正式工作台，跨内容、剧本、镜头、资产、任务、导出、QA，验证提示词锁定、验收记录、QA 修复和脚本回滚等状态真实落库。

## 同步后的统一口径

1. 正式工作台是唯一用户产品入口。
2. 创作画布是正式工作台内的一级模块，不再按独立 Beta 控制台或旧高级编排入口推进。
3. 旧版生产、创作沙盘、高级编排、产品原型 Demo 不再作为新增能力承载面。
4. `/api/prototyping/*` 中仍被正式工作台调用的创意任务接口暂时保留。
5. `/api/workflows*`、`/api/nodes*`、`/api/runs*` 进入下一阶段后端旧执行层审计范围。
6. `npm run e2e:business` 成为正式工作台大改后的固定回归基线。

## 下一阶段建议

1. 审计后端旧执行层接口，明确保留、迁移或封存策略。
2. 把业务流 E2E 从 fixture 扩展到至少 3 个真实项目样本。
3. 继续收口 QA 放行与导出阻塞，让导出中心读取真实修复/复检状态。
4. 继续推进提示词质量、资产继承、多变体命中与模型执行链路的生产级补完。
5. 创作画布继续沿 LibTV 化方向推进，但不得绕开任务中心、QA、资产和导出治理。
