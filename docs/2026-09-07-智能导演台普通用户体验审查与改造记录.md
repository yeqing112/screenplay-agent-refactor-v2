# 智能导演台普通用户体验审查与改造记录

日期：2026-09-07

## 审查范围

智能导演台右侧抽屉的首次进入与“生成只读计划”流程。

审查依据：用户提供的抽屉截图，以及正式工作台真浏览器回归。

## 发现的问题

1. 首屏要求用户先理解 `Skill`、候选操作、`C/D`、`Prompt Version`，把创作助手误做成了开发配置面板。
2. 用户不知道应该先输入什么，也不知道勾选不同操作会造成什么后果。
3. “生成只读计划”和“真实 Agent 草案”没有用普通创作者能理解的语言解释安全边界。
4. 计划结果直接显示 `diagnose`、`continuity_check` 和指纹，破坏了从自然语言输入到自然语言建议的连续体验。
5. 小字号深色辅助文案在截图中对比度偏低；仅凭截图不能确认键盘焦点与读屏顺序，仍需后续辅助功能测试。

## 已实施的改造

1. 首屏改为“今天想让我帮你做什么？”，说明“先给建议，不会自动改内容或提交生成”。
2. 增加四个常用请求：查看下一步、检查镜头连贯性、优化提示词、准备生成视频。
3. `Skill` 和候选操作默认收进“高级设置（通常不需要）”。
4. 主按钮改为“先帮我看看”，明确修改、付费调用或生成前会再次确认。
5. 计划区改为“我建议这样做”，将内部操作名称翻译为面向创作者的动作名称；指纹收进高级信息。
6. 将“真实 Agent 草案（受控）”改为“需要更深入的 AI 建议吗？”，将提示词与证据详情收进高级查看。

## 验收

- 真浏览器：打开抽屉可直接看到自然语言输入、四个常用请求和唯一主动作。
- 真浏览器：点击“检查镜头是否连贯”会填入普通语言目标，并配置相应只读检查。
- 真浏览器：点击“先帮我看看”只生成只读建议，不调用真实 LLM，不写入生产内容。
- 前端：`SmartDirectorDrawer.test.tsx` 通过。
- 前端构建通过。

## 后续建议

在下一轮把历史审计、会话时间线和可承接动作统一收进一个“历史与高级信息”折叠区，并补充键盘焦点、屏幕阅读器和窄屏测试。
