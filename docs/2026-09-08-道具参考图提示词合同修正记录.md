# 道具参考图提示词合同修正记录

## 问题

历史道具模板把“六视图、2 行 3 列、网格排版”写进 `visual_prompt_zh`，而正式资产生成合同要求单张主参考图。运行时直接拼接两者，导致同一个请求同时出现“单张、不分格”和“六视图网格”两套互斥指令。

## 决定

正式生产默认采用“单张主参考图”合同：

- 比例：1:1 或 4:3；
- 主体：单个道具，形制、材质、颜色、关键状态清晰；
- 构图：道具完整入画、主体不裁切，保留整体轮廓与底座，镜头距离适中；
- 背景：纯净背景或真实使用环境；
- 禁止：分格、拼图、多视角排版、文字说明及未声明人物/场景。

多视角图不作为默认主参考图。如果未来某个模型或工作流确实需要多视角，作为独立的“多视角资产变体”能力设计，不能混入主参考图提示词。

## 落地

1. `prompts/scene/props.txt` 改为生成单张主参考图描述。
2. `api.server._build_prop_asset_prompt_contract` 对历史字段只读清理模板残留，保留道具事实；原始提示词不被覆盖。
3. `structured_variant_fields.safe_reference_description` 暴露实际提交给模型的安全描述。
4. 既有候选图不自动删除或替换；重新生成、审核、锁定仍走用户确认门禁。

## 验收标准

- provider-facing prompt 不含 `2行3列`、`六视图`、`多角度展示图` 等模板残留。
- provider-facing prompt 保留道具名称、形制、材质、颜色和关键状态。
- 负向提示词继续明确禁止人物、分格、拼图、多视角排版和文字。
- 同一逻辑适用于所有道具，不依赖书号、资产名或镜头号特例。
