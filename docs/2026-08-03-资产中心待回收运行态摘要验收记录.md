# 2026-08-03 资产中心待回收运行态摘要验收记录

## 本轮目标

把资产中心里的“关联镜头运行态”从简单数量提示，补强为统一的运行态摘要：

- `待回收更新于 ...`
- `待回收任务` 类型汇总
- `最近待回收来源：... · 任务 ID：...`
- 保留逐条待回收任务列表与恢复入口

## 涉及文件

- `web/src/components/ProductWorkspaceAssetsSection.tsx`
- `web/src/components/ProductWorkspaceAssetsSection.test.tsx`
- `web/src/components/productWorkspaceRecovery.ts`

## 实现说明

1. 在资产中心接入共享摘要函数 `summarizePendingStoryboardTasks(...)`。
2. `关联镜头运行态` 卡片补充：
   - 最近待回收更新时间
   - 待回收类型聚合文本
   - 最近待回收来源说明
3. 资产中心里的“来源”按资产工作流语义展示为：
   - `任务类型 / 第 N 集 / 镜头 X`
   - 这样能直接回答“这个资产当前卡在哪个镜头上”
4. 保留原有：
   - 去任务中心继续回收
   - 去镜头工作台定位镜头
   - 逐条任务明细

1. 资产中心现在不只是告诉用户“有任务挂着”，而是更明确地告诉用户“这个资产卡在了哪一个镜头的哪一种结果上”。
