## 对应验收标准

1. 多镜头 fallback reference 在创建后，必须可写入全部目标镜头。
2. 同一 reference 删除后，必须从全部目标镜头中移除，不能只删 1 个镜头。
3. `removed_storyboard_references` 必须准确等于实际移除的 storyboard reference 数量。
4. 删除完成后，storyboard 与 visual assets 两侧都不能残留该 reference token。
