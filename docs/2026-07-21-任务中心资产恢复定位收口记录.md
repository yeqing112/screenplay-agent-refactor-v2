# 2026-07-21 任务中心资产恢复定位收口记录

## 本轮目标

补强“任务中心 -> 资产中心”的恢复定位精度，避免在以下场景里命中错误资产版本：

- 同一人物存在 `基础定妆 / 分集默认 / 分镜精调` 多版本
- 同名资产跨镜头复用
- 任务恢复时只带了镜头上下文和资产名称，没有直接带回完整页面状态

目标是让恢复入口尽量回到“当前镜头真正需要处理的那一版资产”，而不是同名资产里的第一个。

## 代码调整

调整文件：

- [web/src/components/productWorkspaceAssetViewController.ts](D:/Work/Project/screenplay-agent-refactor-v2/web/src/components/productWorkspaceAssetViewController.ts)

原行为：

- `resolveAssetTaskNavigationTarget(...)` 采用多段 `find(...)` 短路
- 一旦先命中“同名”“同集”或“某个已绑定镜头”，就直接返回
- 遇到多版本角色资产时，容易落到分集默认，而不是当前镜头精调版本

新行为：

- 改为统一评分排序，再返回最高分候选
- 当前评分信号包含：
  - 显式 `assetId`
  - 镜头绑定命中
  - 资产标签命中
  - 分集覆盖命中
  - 当前镜头候选名命中
  - 版本作用域优先级（`shot_variant > episode_default > base_identity`）
  - 是否已有预览图 / 锁定图

这让恢复定位在“多版本同名资产”场景下更稳定。
