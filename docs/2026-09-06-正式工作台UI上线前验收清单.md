# 正式工作台 UI 上线前验收清单

更新时间：2026-09-06

## 结论

正式工作台的“生产收敛”目标已具备发布候选条件：普通创作者在主要页面能够看到当前阶段、阻断原因和一个明确的下一步；模型、对象存储、历史、诊断与导出等专家能力仍完整保留，但默认不挤占生产视图。

这不是“全项目已可正式生产”的放行结论。UI 相关的主要剩余正式阻塞是公网资产域名；真实生产还应分别完成基础设施、模型额度和真实媒体链路验收。

## 已验证的用户路径

| 路径 | 可观察结果 | 证据 | 结论 |
| --- | --- | --- | --- |
| 项目控制台 → 改编方向 | 当前阶段和唯一行动都指向“锁定改编方向” | 正式浏览器 `full_pipeline_test_novel` | 通过 |
| 内容准备 | 已有内容时导入工具默认折叠；展开后仍同时提供长篇与短篇导入 | 真实浏览器 + 隔离 E2E | 通过 |
| 改编方向 | 未锁定时 Skill 配置保持可见；锁定后收起但可按需调整 | 真实浏览器 + 隔离 E2E | 通过 |
| 剧本工作台 | 正文、上游原因、锁稿/放行在首层；QA/版本历史按需展开 | 真实浏览器 + 隔离 E2E | 通过 |
| 资产中心 | 卡片显示待补图、影响范围和建议下一步；结构、治理、绑定明细折叠 | 正式浏览器 | 通过 |
| 镜头工作台 | 上游未放行时不显示下游执行入口；放行路径保留 Prompt、验收和生成能力 | 业务 E2E + 既有浏览器回归 | 通过 |
| 任务中心 | 默认按“需要你处理 / 正在执行 / 历史”组织；首要任务可直接跳转 | 正式浏览器 + 隔离 E2E | 通过 |
| 导出中心 | 只突出第一个交付阻塞，其余检查、格式与历史按需展开 | 正式浏览器 + 隔离 E2E | 通过 |
| 模型与存储 | 首层只显示真实生效默认和中转状态；密钥、迁移、能力矩阵收进管理员层 | 真实浏览器 + 隔离 E2E | 通过 |
| QA 修复与回滚 | 默认仅显示待处理；历史可由“按处理状态筛选 → 全部状态”查看、回滚 | 隔离 E2E | 通过 |

## 自动化验证基线

- `npm --prefix web test`：45 个测试文件、251 项断言通过。
- `npm --prefix web run build`：TypeScript 检查和生产构建通过。
- `npm run e2e:business`：通过。使用独立端口、隔离 `book 999902` 和 Prompt mock；日志输出 `Business flow E2E passed.`，执行完成后夹具已清理。
- QA 低频筛选已收敛到“高级：筛选问题范围、历史与排序”；隔离回归再次通过，确认展开筛选、切换历史、打开版本并回滚的路径可用。
- 隔离回归覆盖的所有 Prompt 调用都走 mock；不调用真实 LLM、图片或视频 provider。

## 发布前必须处理

1. 配置稳定的 HTTPS 公网自定义域名。
   当前七牛 `clouddn.com` 测试域名只适合调试，不应作为 H3 多参考和生产资产的稳定公网地址。域名生效后应重新验证上传资产、读取公网 URL、视频多参考提交和回收。
   当前模型页会阻断任何 HTTP、局域网、格式错误或 `clouddn.com` 域名，不再把“已保存 Bucket/密钥”误显示为“中转可用”。同一规则已下沉至对象存储核心：任何需要强制发布的 H3 多参考图、交接帧和生产迁移，在写入对象存储前都会拒绝临时/非 HTTPS 域名，不能通过直接调用接口绕过页面门禁。

2. 在发布环境完成一次真实媒体链路灰度。
   选择已锁定的非敏感测试资产，逐项确认图片上传回收、对象存储持久化、视频多参考 URL 可访问、任务状态回收和验收回填。真实模型调用必须保持页面双确认。

## 发布前建议完成

1. 使用键盘完成一次完整主流程；当前已覆盖导航、管理员折叠和关键状态播报，但不能据此宣称完整读屏兼容。
2. 在常用桌面分辨率与窄窗口复核镜头、资产和导出页，尤其检查较长资产名称和多镜头影响范围。
3. 由真实创作者使用一个新项目完成“导入内容 → 锁定方向 → 剧本 → 资产 → 镜头 → 验收”演练，记录不需要解释就能完成的比例和卡点。

## 不应误判为产品缺陷的状态

- 当前项目的“改编方向未锁定”“剧本待锁稿”“资产待补图”“QA 待处理”等是项目真实业务数据，不是 UI 错误。
- 历史视频、失败资产、Prompt Version、验收与审计记录被保留在按需展开的历史/高级层，未删除。
- 外部模型、对象存储配置与真实生成仍需要显式确认；UI 收敛没有绕过此安全边界。

## 验收边界

本清单基于真实浏览器交互、隔离 Playwright 业务回归、前端单元测试和生产构建。它不替代真实模型付费调用、生产域名证书、性能压测、移动端适配或专业读屏软件的验收。

## 智能导演台 Agent（独立验收边界）

- 本清单仅覆盖\"正式工作台全系统 UI 收敛\"的发布候选状态；智能导演台 Agent 是独立产品层，验收清单独立维护。
- 在 Agent 阶段化落地完成且 Phase 1 抽屉式对话 UI 验收前，正式工作台的上线不依赖 Agent；Agent 上线也不替代本清单中的 HTTPS 公网资产域名与真实媒体灰度。
- Agent 的可执行性依赖于既有受控链路：它只能使用已通过受控调用、对象存储与生产门禁验证的资产与模型；不得绕过生产链路的真实灰度结论。
- Agent 的审计日志与回放能力由 Phase 0 / Phase 1 的验收标准决定；正式工作台不为其预置 UI。
