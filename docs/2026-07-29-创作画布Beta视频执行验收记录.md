# 2026-07-29 创作画布 Beta 视频执行验收记录

## 验收目标

验证创作画布 Beta 已补齐 L2 第三个关键执行动作：

- 在画布中选中单个分镜节点
- 仅在存在已采纳首帧时开放 `生成视频`
- 发起真实 `generate-video` 请求
- 请求体显式带上 `firstFrameAssetId`、`referenceAssetIds`、`generationChain`
- 进入真实创意任务轮询链路
- 保留 `去任务中心继续回收视频` 恢复入口

## 本次实现

涉及文件：

- `web/src/components/ProductWorkspaceCanvasBetaSection.tsx`

新增能力：

1. 创作画布分镜详情卡新增 `生成视频`
2. 新增 `视频任务恢复 ID` 本地状态同步
3. 复用正式分镜工作台的视频生成输入规则：
   - `compileIfMissing: true`
   - `firstFrameAssetId: adopted image id`
   - `referenceAssetIds: effectiveReferenceAssetIds`
   - `generationChain: canvas_generate_video`
4. 复用现有创意任务恢复链路：
   - `GET /api/prototyping/tasks/{taskId}`
   - `POST /api/prototyping/tasks/{taskId}/reconcile`
   - `upsertPendingStoryboardTask(... kind: 'video')`
5. 在画布中显示本次视频执行的输入摘要：
   - 已采纳首帧
   - 结构化参考图数量与来源
   - 待回收视频任务

## 真浏览器验收

验收地址：

- 前端：[http://127.0.0.1:5175](http://127.0.0.1:5175)

验收方式：

- 使用真实浏览器打开 `三个和尚 -> 正式工作台 -> 创作画布 Beta`
- 选中存在已采纳首帧的镜头 `镜头 1`
- 对浏览器网络做本地拦截，避免实际触发付费视频模型

验收步骤：

1. 打开 `三个和尚`
2. 进入 `正式工作台 -> 创作画布 Beta`
3. 点击 `镜头 1`
4. 在右侧 `单镜头执行` 区域确认看到：
   - `已采纳首帧：是`
   - `结构化参考图：5 张（compiled）`
   - `生成视频`
   - `去任务中心继续回收视频`
5. 点击 `生成视频`
6. 观察请求、轮询与回写文案

浏览器观测结果：

- 成功出现 `生成视频` 与 `去任务中心继续回收视频`
- 实际发起请求：
  - `POST http://127.0.0.1:5175/api/books/14/storyboard/1/1/generate-video`
- 实际进入任务轮询：
  - `GET http://127.0.0.1:5175/api/prototyping/tasks/canvas-video-002`
- 请求体内容为：

```json
{

  "firstFrameAssetId": "image-87712c282a",
  "referenceAssetIds": ["ref-8", "ref-42", "ref-41", "ref-34", "ref-49"],
  "generationChain": "canvas_generate_video"

```

- 页面出现成功文案：
  - `视频已生成并写回镜头。`
