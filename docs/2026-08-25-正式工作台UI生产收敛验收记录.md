# 2026-08-25 正式工作台 UI 生产收敛验收记录

## 改动目标

本轮按“默认清爽，按需展开”的生产收敛路线优化正式工作台前端 UI，不删除核心生产能力，重点降低镜头工作台和项目控制台的信息噪音。

## 已完成改动

- 左侧导航降噪：移除重复的大段工作台说明与底部项目说明卡，保留项目名、正式工作台入口和项目状态。
- 将“刷新项目数据”从左侧导航区移到顶部右侧工具区。
- 项目控制台指标卡合并为“项目状态摘要”一条状态带。
- 项目控制台“当前下一步”和“建议动作”合并为一个“下一步行动”卡，只保留一个默认主按钮，其他建议折叠到“更多建议动作”。
- 镜头列表将长句“下一步：……”压缩为短标签，例如“缺参考 / 待重编 / 缺分镜图 / 待视频 / 待验收”，完整动作保留在 hover title。
