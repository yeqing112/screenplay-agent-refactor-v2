# 2026-08-27 MiniMax H3 异步视频适配层第一阶段验收记录

## 结论

本轮已完成 MiniMax H3 异步视频 provider adapter 第一阶段。

该阶段目标不是默认打开真实视频生成，而是让系统具备以下能力：

- 模型管理可配置 `minimax-h3-async` 视频模型。
- 后端可构造 MiniMax H3 v2 create payload。
- 后端可提交、轮询、恢复 MiniMax H3 异步任务。
- 单元测试用 mock HTTP 锁定 payload 与回收协议，不触发真实扣费任务。

## 接入边界

- 默认视频模型不自动切换为 MiniMax H3。
- 模型管理“测试当前草稿”只做结构校验，不调用真实生成接口。
- 正式工作台机器提示词 API 提交任务链仍保留显式提交边界。
- 下一阶段如要真实调用 MiniMax H3，必须继续保留“用户显式确认、任务中心追踪、可回收”的安全边界。

## 已完成实现

- 新增 provider：
  - `minimax-h3-async`
- 模型注册表：
  - 允许 video 能力配置 MiniMax H3。
  - 允许 MiniMax H3 作为 video default，但不会自动替换当前默认。
  - 测试连接返回“结构校验通过，不发起真实扣费任务”。
- 后端适配器：
  - `submit_minimax_h3_generation`
  - `poll_minimax_h3_generation`
  - `reconcile_minimax_h3_generation`
  - `_build_minimax_h3_video_payload`
- 支持 payload：
  - 文生视频：text + `ratio`
  - 首帧图生视频：text + `image_url` + `role=first_frame`，不传 `ratio`
- 任务恢复：
  - `/api/prototyping/tasks/{task_id}` reconcile 已能识别 `minimax-h3-async`
- 模型管理前端：
  - provider 下拉新增 `minimax-h3-async`
  - base URL 建议 `https://metaso.cn/api/minimax`
  - 模型名建议 `MiniMax-H3`
  - 默认参数建议 `resolution=768P / duration=5 / ratio=16:9 / aigc_watermark=false / poll_interval_seconds / poll_timeout_seconds`

## 2026-08-28 补充：metaso.cn 兼容平台口径

经对照 `meta-sota/ComfyUI-MiniMaxH3-API` 插件，当前目标平台为 metaso MiniMax H3 兼容 API：

- Base URL：`https://metaso.cn/api/minimax`
- Create：`POST /v2/video_generation`
- Query：`GET /v2/query/video_generation/{task_id}`
- Token：`Authorization: Bearer mk-...`
- 文生视频：`content=[{type:"text", text}]`，并传 `ratio`
- 首帧图生视频：`content=[text, {type:"image_url", image_url:{url}, role:"first_frame"}]`，不强制传 `ratio`
- `aigc_watermark` 默认不进入请求体；只有显式开启时发送 `true`
- `fail / failed / expired / error / cancelled / canceled` 均视为失败状态
