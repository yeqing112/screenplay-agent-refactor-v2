# 2026-07-27 任务中心重发输入继承验收记录

## 验收目标

- 明确任务中心中的“重新发起任务”是否复用旧输入
- 在真页面中向用户展示：
  - 是否沿用任务提交时的提示词版本
  - 是否自动切换到镜头当前版本
  - 是否继续复用首帧
  - 是否继续复用静态参考图

## 实现范围

- `web/src/components/productWorkspaceTaskCenterDetailPanels.tsx`
- `web/src/components/productWorkspaceTaskCenterDetailPanels.test.tsx`

## 实现说明

任务中心“创意任务恢复”操作区新增一段 `重新发起说明`，直接基于当前任务元数据生成：

- 若任务记录了 `taskPromptVersion`
  - 显示“重发会沿用任务提交时的提示词版本 vX”
- 若镜头当前版本与任务版本不一致
  - 显示“不会自动切换到镜头当前版本 vY”
- 若记录了首帧
  - 显示“继续使用首帧 xxx”
- 若记录了静态参考图
  - 显示“继续挂载 N 张静态参考图”

该说明与现有后端行为一致：

- `/api/prototyping/tasks/{task_id}/restart`
- 当前确实是基于原始 `request_payload` 重新入队
- 不是自动抓取镜头工作台上的最新 prompt / 最新绑定重新生成

## 当前残留

- 当前仍然只是“提示风险”，还没有做到：
  - 一键按镜头当前最新版本重发
  - 重发前可选“沿用旧输入 / 切换最新镜头版本”
  - 重发前可选是否重新抓取最新首帧与最新静态参考图
