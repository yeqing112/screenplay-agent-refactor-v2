# 智能导演台 Agent：阶段任务与验收标准

日期：2026-09-06  
落档：\docs/2026-09-06-智能导演台Agent-用户决策与落档方案.md\  
本文件状态：阶段任务与验收标准，与生产链路并行推进。

## 共享原则

- Agent 不能绕过现有 DecisionPacket、Prompt Version、资产锁定、对象存储生产门禁与真实媒体双确认。
- 所有外部模型调用、对象存储写入、版本覆盖必须由用户在 UI 显式确认。
- 不为 book / 角色 / 资产 / 镜头做特例；规则须通用、可审计、可回滚。
- 审计与回放必须独立可查，与生产链路审计不重复建表。

## Phase 0：导演运行时与只读影子

### 任务

- 新增 \DirectorPlan\ 领域模型：objective / scope / evidence_snapshot / steps / preconditions / blocking_issues / approval_policy / cost_envelope / rollback_anchor。
- 新增 \gent_session\、\gent_audit_log\ 持久化模型，含证据指纹、Plan ID、Step、确认人。
- 实现状态机：草案 → 等待确认 → 执行中 → 验收 → 完成或阻塞。
- 只读计划 API：在不动 UI 的前提下，对真实项目跑\"只产计划\"影子运行。
- Agent 模型注册入口：仅占位与配置项，不接 LLM 网关。

### 验收

- Plan 能准确指出缺失资产、过期 Prompt、待确认调用与质量风险。
- Plan 不触发任何 C/D 档工具。
- 影子运行与人工操作结果一致；审计日志可回放。
- \
pm run test\ 与 \
pm run build\ 通过。

## Phase 1：抽屉式对话 UI（只读 + 草案）

### 任务

- 全局悬浮按钮 + 右侧抽屉，覆盖工作台。
- 三栏：会话 / 计划与草案 / 输入与确认。
- 工作台选中对象可作为上下文注入对话。
- 对话输出必须链接到具体对象和版本。
- Agent 模型接入：使用「模型管理 → 管理员配置」中的独立配置。

### 验收

- 抽屉默认隐藏；显示时不遮挡首屏当前阶段/原因/唯一下一步。
- 只触发 A、B 档；C、D 档必须显式确认。
- 真实浏览器可验证。

## Phase 2：受控编排

### 任务

- A–D 档工具映射与注册。
- 暂停 / 恢复 / 失败重试 / 任务时间线。
- 成本上限与预算守护。
- 与任务中心、QA、导出中心联动。

### 验收

- C、D 档逐次确认；超预算自动暂停。
- 任务时间线与现有任务中心可对齐。
- 审计与回放覆盖全部 A–D 档执行。

## Phase 3：首批 4 个 Skill

### 任务

- 短剧生产 Skill：承接当前全链路。
- TVC Skill：Brief、卖点、时长、品牌禁忌、平台规格、镜头节奏。
- 儿童教育 Skill：年龄段、知识目标、安全、语言难度、互动节奏。
- 连续性 Skill：相邻镜头连续性诊断与衔接建议。
- Skill 注册表、版本化、灰度开关与第三方受控扩展。

### 验收

- 每个 Skill 仅输出结构化计划与草案；不复制独立数据表或前端。
- 第三方 Skill 必须有受控清单 + 沙箱；不允许直接访问数据库、密钥或任意 Shell。

## Phase 4：来源与交付治理

### 任务

- 内部 provenance 图谱：素材来源、上传者/生成模型、Prompt Version、参考图、模型参数、外部任务号、文件哈希、验收结论、后续编辑链。
- 导出清单：交付前自动产出内容凭证与可审计清单。
- C2PA / Content Credentials 可行接入评估。

### 验收

- provenance 完整、可追溯。
- 导出清单可用于交付前自检。
- C2PA 接入评估有明确结论：接入 / 不接入 / 延后。

## 与生产灰度、HTTPS 资产域名的关系

- Agent 的可执行性依赖于既有受控链路，不替代或绕过。
- HTTPS 资产域名、视频模型参数仍由真实灰度验证。
- Agent 阶段化验收不替代\"正式工作台上线前验收清单\"。
