# Information Architecture V3

## Top level

```text
项目
├─ 项目首页
│  ├─ 当前进度
│  ├─ 唯一下一步
│  └─ 阻塞摘要
├─ 创作
│  ├─ 内容准备
│  ├─ 改编方向
│  ├─ 剧本工作台
│  ├─ 镜头工作台
│  └─ 创作画布
├─ 生产与检查
│  ├─ 资产中心
│  ├─ QA 修复
│  ├─ 任务中心
│  └─ 导出中心
└─ 管理
   └─ 模型与存储设置
```

## Object hierarchy

```text
项目 → 集 → 场 → 镜头 → 资产/提示词/候选媒体/正式媒体 → 审核记录
```

每个页面应保持当前对象面包屑：`项目 / 第 1 集 / 场景 A / 镜头 214`。工程对象（PromptIR、GenerationExecution、formal asset binding）挂在“专业详情”下。

## Navigation rules

1. 侧栏只负责一级页面切换。
2. 页面内 Tab 只切换同一对象的工作面，不承载全局生产阶段。
3. 阻塞点击进入目标页面并自动打开对应对象；不可只跳到空白页面。
4. 返回操作保留上次 episode、shot 和 step。
5. 标准视图隐藏内部 ID；复制链接和专业视图可显示。

## Page ownership

| 信息 | 权威页面 | 允许的写入 |
|---|---|---|
| 原始内容与章节 | 内容准备 | 导入草稿、元数据 |
| 项目方向 | 改编方向 | 新方向版本、锁定 |
| 剧本版本 | 剧本工作台 | 新版本、审核、回退 |
| 镜头计划 | 镜头工作台 | ShotPlan/ShotDirection 草稿与版本 |
| 视觉资产 | 资产中心 | 资产语义、绑定、参考图 |
| 执行与阻塞 | 任务中心 | 状态处理、重试、跳转 |
| 质量与交付 | QA/导出中心 | QA 决策、导出记录 |
