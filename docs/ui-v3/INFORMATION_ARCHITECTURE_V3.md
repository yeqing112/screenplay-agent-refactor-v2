# Information Architecture V3

## Top level

```text
项目
├─ 项目首页
│  ├─ 当前进度
│  ├─ 唯一下一步
│  └─ 阻塞摘要
├─ 创作
│  ├─ 内容准备
│  ├─ 改编方向
│  ├─ 剧本工作台
│  ├─ 镜头工作台
│  └─ 创作画布
├─ 生产与检查
│  ├─ 资产中心
│  ├─ QA 修复
│  ├─ 任务中心
│  └─ 导出中心
└─ 管理
   └─ 模型与存储设置
```

## V3 candidate validated against current workflow

| V3 一级入口 | 当前入口映射 | 结论 |
|---|---|---|
| 制片台 | 项目控制台 + Production Workspace V2 + 一部分任务中心 | 合并；保留全局进度、集卡片、Review Queue、活动和阻塞 |
| 剧本与导演 | 内容准备 + 改编方向 + 剧本工作台 + 智能导演台 | 合并；按内容、方向、导演方案、剧本审核分步呈现 |
| 镜头工坊 | 镜头工作台 + 创作画布 + Production Workspace V2 | 合并；Shot 是基本工作单元，关键帧/图片/视频在同一工作面 |
| 资产库 | 资产中心 + 人物检查 | 合并；人物、场景、道具、风格、媒体以资产身份组织 |
| 交付与设置 | QA 修复 + 导出中心 + 模型管理 | 分成“交付”和“设置”子页；生产页不展示 provider 配置 |

这个映射来自当前导航、组件挂载关系、真实任务中心和镜头页截图验证，不是对现有 11 个入口的机械改名。

```text
资产库

交付与设置

```

## Object hierarchy

```text
项目 → 集 → 场 → 镜头 → 资产/提示词/候选媒体/正式媒体 → 审核记录
```

每个页面应保持当前对象面包屑：`项目 / 第 1 集 / 场景 A / 镜头 214`。工程对象（PromptIR、GenerationExecution、formal asset binding）挂在“专业详情”下。

## Navigation rules

1. 侧栏只负责一级页面切换。
2. 页面内 Tab 只切换同一对象的工作面，不承载全局生产阶段。
3. 阻塞点击进入目标页面并自动打开对应对象；不可只跳到空白页面。
4. 返回操作保留上次 episode、shot 和 step。
5. 标准视图隐藏内部 ID；复制链接和专业视图可显示。

## Page ownership

| 信息 | 权威页面 | 允许的写入 |
|---|---|---|
| 原始内容与章节 | 内容准备 | 导入草稿、元数据 |
| 项目方向 | 改编方向 | 新方向版本、锁定 |
| 剧本版本 | 剧本工作台 | 新版本、审核、回退 |
| 镜头计划 | 镜头工作台 | ShotPlan/ShotDirection 草稿与版本 |
| 视觉资产 | 资产中心 | 资产语义、绑定、参考图 |
| 执行与阻塞 | 任务中心 | 状态处理、重试、跳转 |
| 质量与交付 | QA/导出中心 | QA 决策、导出记录 |
