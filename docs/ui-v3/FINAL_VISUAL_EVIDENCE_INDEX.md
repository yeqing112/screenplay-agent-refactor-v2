## Visual QA notes

- Dashboard 首屏按 Project Context → Next Best Action → Episode Progress / Production State 排列。
- Shot Studio 同屏呈现 Scene-grouped Navigator、三联画媒体、生产状态 rail、Director Intent 和 Production Details 入口。
- Review Inbox 使用 Filters / Queue / Review Desk 三栏，大媒体预览和固定决策栏。
- Director Workspace 使用 B 的 editorial serif 局部，生产正文保持 sans。
- 1280px 通过 Context collapse 保持完整操作；低于 1280px 使用 drawer / stacked 降级。
