# Production UI V3 Visual Direction Board

本阶段只提供候选视觉语言，最终选择留给产品负责人。三套方向使用同一业务 fixture 和同一核心流程，差异来自空间结构、信息密度、媒体占比、导航和审核方式。

## Direction A — Cinematic Command

- **Design philosophy**：像电影后期控制台；让当前画面、阶段和唯一下一步占据空间中心。
- **Primary user**：导演、视觉总监、需要沉浸式判断画面的创作成员。
- **Information density**：中等；减少文字和表格，用大画面与状态节点建立节奏。
- **Navigation concept**：顶部极简工作流导航，Shot Studio 左侧导航、右侧上下文。
- **Media emphasis**：最高；关键帧和审核预览占据主画面。
- **Review interaction**：大预览 + 右侧决策盒，适合快速判断单条审核。
- **Strengths**：视觉层级明确、长时间观看画面舒适、Shot 的当前阶段很突出。
- **Weaknesses**：40+ 镜头扫描需要依赖左侧导航和颜色/标签；文本证据密度较低。
- **Risk**：在复杂项目中可能需要更多上下文切换。
- **Best-fit scenario**：镜头创作、关键帧和视频审核。

## Direction B — Editorial Studio

- **Design philosophy**：像编辑型创作工作室；先读懂故事和导演意图，再作审核决定。
- **Primary user**：导演、编剧、制片和内容人员的混合团队。
- **Information density**：中等偏低；通过段落、引用和说明建立理解。
- **Navigation concept**：横向章节导航，页面以内容阅读流承接。
- **Media emphasis**：中等；媒体与文本平衡，强调解释和语义。
- **Review interaction**：左侧审核队列 + 中央阅读/预览 + 右侧上下文。
- **Strengths**：AI 为什么这样拍、审核原因和导演意图最易理解；学习曲线较平缓。
- **Weaknesses**：连续处理大量 Shot 时，队列扫描速度可能低于高密度方向。
- **Risk**：长文本和媒体同时出现时，首屏信息可能变长。
- **Best-fit scenario**：导演方案、剧本与分镜审核、跨角色协作。

## Direction C — Precision Production

- **Design philosophy**：像专业制片操作台；将状态、队列和 Shot 切换压缩到可扫描网格。
- **Primary user**：制片 operator、需要管理 40+ 镜头和多个并行任务的用户。
- **Information density**：最高；以紧凑的列表、阶段条和右侧审核台支撑批量操作。
- **Navigation concept**：固定顶部导航 + 左侧 Shot Navigator / Inbox filters。
- **Media emphasis**：中等；媒体卡片保持足够辨识度，更多空间给状态和队列。
- **Review interaction**：列表/队列与右侧 review desk 同屏，适合连续审核。
- **Strengths**：Shot 扫描、并行生成和阻塞定位最快；适合长项目。
- **Weaknesses**：首次学习成本较高；视觉媒体的沉浸感弱于 A。
- **Risk**：高密度需要严格控制状态颜色、字号和焦点，否则容易接近后台系统。
- **Best-fit scenario**：40+ 镜头制片、任务恢复、批量审核。

## Selection guidance

请从以下维度逐屏比较，不设总分或默认赢家：5 秒清晰度、审核速度、长时间使用、40+ 镜头扩展性、媒体聚焦、信息密度、学习成本、无障碍、实施复杂度。允许混合选择，例如 A 的 Shot Studio + B 的 Dashboard + C 的 Review Inbox。
