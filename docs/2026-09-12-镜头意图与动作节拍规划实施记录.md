# 镜头意图与动作节拍规划实施记录

日期：2026-09-12

## 本次实施

- 新增 `core/shot_planner.py`，提供两个确定性规划器：
  - `build_shot_intent_plan`：从已声明的 `shot_purpose`、`core_action`、`action_beats`、情绪弧线和起止状态生成可审阅意图摘要。
  - `build_action_timing_plan`：把已声明动作节拍分配到毫秒时间线；显式时长优先，未声明部分只分配剩余时间，超出总时长返回 `conflict`。
- 两个规划器均不调用 LLM、不访问数据库、不按书号/角色/关键词推断，不重写原始镜头。
- 缺失信息保留在 `unknowns`，让上游决定补证据、人工确认或阻断。
- `core.prompt_ir.build_shot_ir_from_context` 接入规划结果，`serialize_shot_ir` 暴露 `shot_intent_plan` 与 `action_timing_plan`，供 Prompt Compiler、可拍性门禁和工作台审阅使用。
- Prompt Compiler 在吸收 LLM 动作节拍后重新计算并回填规划结果，避免显示旧的确定性节拍。
- 镜头工作台对 `needs_information / conflict` 提供“先补充镜头信息 / 先调整动作时长”入口，入口只定位到概览步骤，不直接写入或提交生成。
