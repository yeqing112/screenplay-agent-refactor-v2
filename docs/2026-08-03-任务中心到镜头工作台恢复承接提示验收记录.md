# 2026-08-03 任务中心到镜头工作台恢复承接提示验收记录

## 验收目标

确认正式产品工作台中，`任务中心 -> 视频结果回收 -> 前往镜头工作台` 的恢复承接提示能够稳定显示，不会在定位镜头后立即丢失。

## 修复内容

- 修复文件：`web/src/components/ProductWorkspaceStoryboardSection.tsx`
- 根因：
  - 镜头工作台收到 `recoveryFocus` 后，会在 `useEffect` 中立刻调用 `onDismissRecoveryFocus()`
  - 结果是镜头已经定位成功，但“任务中心承接中”的上下文马上被清空，用户看不到承接提示
- 调整：
  - 移除镜头工作台中的自动清空逻辑
  - 为“任务中心承接中”提示增加手动关闭按钮 `关闭提示`

## 补充发现

本轮真实浏览器排查还发现一个独立问题：

- 项目列表存在同名项目时，人工点选验收样本容易误入另一份同名数据
- 这不会影响本次承接提示修复本身，但会影响后续真实验收效率

建议将其纳入后续单独治理项：

- 项目卡片补充更明确的项目标识
- 或增加按 `bookId / 创建时间 / 状态阶段` 的辅助识别能力
