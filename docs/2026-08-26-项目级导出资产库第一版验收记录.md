# 2026-08-26 项目级导出资产库第一版验收记录

## 背景

交付包历史和机器提示词导出历史此前虽然都落在 `ProductionExportRecord`，但前端体验是分散的：导出中心主要看交付包，镜头工作台只看当前镜头机器提示词导出。生产交付需要一个项目级视角，能统一检索“交付包 / 阻塞快照 / 机器提示词导出快照”。

## 本轮改动

- 导出中心的历史区从“交付历史中心”继续升级为“项目级导出资产库”第一版。
- 新增资产类型识别：
  - `record_type=storyboard_machine_prompt_export` 或 `export_format=storyboard-machine-prompt-*` 识别为“机器提示词”
  - 其他记录识别为“交付包”
- 新增资产类型筛选：
  - 全部资产
  - 交付包
  - 机器提示词
- 新增多关键词检索：
  - 可按模型、镜头号、场景、摘要、格式、状态、阻塞原因检索
  - 多关键词采用 AND 逻辑，例如 `便利店 minimax`
- 记录卡增强：
  - 显示“交付包 / 机器提示词”类型标签
  - 机器提示词记录显示模型、导出通道、镜头号、API 是否提交
  - 机器提示词记录可直接定位回镜头工作台
  - 所有记录可复制完整快照 JSON

## 当前边界

- 第一版仍复用 `/api/books/{book_id}/export-records` 全量列表；后端分页和查询参数留到下一轮。
- 机器提示词记录支持定位镜头和复制快照，但尚未提供“一键恢复为导出草稿”。
- 交付包和机器提示词已经统一可见，但更完整的“导出资产库”后续还应支持复制完整导出包、对比历史快照和批量导出。

## 后续建议

1. 为 `/api/books/{book_id}/export-records` 增加 `record_type / episode / status / format / query / limit / offset` 查询参数。
2. 支持机器提示词历史快照恢复为 WebUI 临时草稿，不反写导演语言或 Shot Schema。
3. 支持交付包历史快照复制完整 JSON，或重新下载对应格式。
