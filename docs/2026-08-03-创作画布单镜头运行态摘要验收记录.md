# 2026-08-03 创作画布单镜头运行态摘要验收记录

## 本轮目标

把 `创作画布 Beta` 右侧 `单镜头执行` 面板里的运行态展示，从零散的待回收任务 ID，补强为统一的运行态摘要：

- `当前镜头运行态`
- `待回收更新于 ...`
- `最近执行`
- `待回收任务` 类型汇总
- `建议动作`
- `最近待回收来源：... · 任务 ID：...`

## 涉及文件

- `web/src/components/ProductWorkspaceCanvasBetaSection.tsx`
- `web/src/components/ProductWorkspaceCanvasBetaSection.test.ts`
- `web/src/components/productWorkspaceRecovery.ts`

## 实现说明

1. 在画布单镜头详情接入：
   - `readShotRuntimeState(...)`
   - `summarizePendingStoryboardTasks(...)`
2. 新增 `buildCanvasShotRuntimeSummaryCard(...)`，统一画布侧的运行态摘要语义。
3. 保留原有：
   - 待回收提示词 / 首帧 / 视频任务 ID
   - 去任务中心继续回收按钮
   - 重编译、首帧生成、视频生成按钮
4. 同时补上 `canvasRuntimeVersion` 依赖，让本地恢复态刷新后，画布详情能同步重读运行态。

## 本轮价值

1. 画布单镜头执行面板终于和镜头工作台、资产中心使用同一套运行态摘要语义。
