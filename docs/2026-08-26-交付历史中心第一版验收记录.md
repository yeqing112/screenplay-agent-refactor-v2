# 2026-08-26 交付历史中心第一版验收记录

## 背景

导出中心此前只在当前分集下展示交付记录，适合临时查看，但不足以支撑生产交付追溯。上线前需要把导出记录升级为可筛选、可查看完整快照、可回到对应分集继续处理的交付历史中心。

## 本轮改动

- 正式工作台导出中心将“交付记录”升级为“交付历史中心”。
- 新增历史汇总：
  - 全部记录数
  - 已完成记录数
  - 阻塞记录数
- 新增筛选：
  - 当前集 / 全部集 / 指定分集
  - 全部状态 / 已完成 / 阻塞
  - 全部格式 / JSON / 交付快照 / Word / PDF / Final Draft 等历史格式
- 每条记录新增操作：
  - 定位分集
  - 复用历史格式提示
  - 查看 / 收起完整快照 meta
- 完整快照 meta 用于追溯：
  - `blocked_codes`
  - `blocked_reasons`
  - `qa_delivery_gate`
  - `version_label`
  - 历史导出上下文

## 当前边界

- 第一版仍复用现有 `/api/books/{book_id}/export-records` 全量列表接口；目前记录规模足够，暂不引入分页。
- “复用历史格式”本轮先做为定位与操作提示，不自动触发新的下载或写入，避免用户误操作生成新交付记录。
- 机器提示词的单镜头导出历史仍保留在镜头工作台；后续如要做全项目统一“导出资产库”，可再把机器提示词导出记录与交付包导出记录合并检索。

## 后续建议

1. 为导出历史增加后端分页、格式/status/episode 查询参数。
2. 支持从历史快照恢复或复制完整导出包 JSON。
3. 将机器提示词导出历史与交付包历史统一成项目级导出资产库。
