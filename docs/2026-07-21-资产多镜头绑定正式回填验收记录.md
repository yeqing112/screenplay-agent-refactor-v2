# 2026-07-21 资产多镜头绑定正式回填验收记录

## 背景

- 验收日期：2026-07-21
- 项目：`三个和尚`
- 前端：`http://127.0.0.1:5175`
- 后端：`http://127.0.0.1:18765`

在前两轮修复后：

- 资产中心可以通过 `metaInfo.shotIds` 把参考图一次回写到多个镜头
- 删除参考图时，也可以按同一组镜头完整清理 storyboard references

但仍存在一个生产级缺口：

- 资产卡片仍显示 `待同步绑定`
- 说明系统只把“多镜头命中关系”写进了 storyboard reference
- 没有把这组关系正式回填到资产自己的 `shot_ids`

这会导致：

1. 页面上看起来仍像半完成状态
2. 后续没有参考图时，资产本体仍然丢失正式镜头绑定
3. 多镜头命中关系无法沉淀成长期可维护的数据

## 对应验收标准

1. fallback 多镜头命中不能只写入 storyboard，必须同步回填到资产 `shot_ids`
2. 资产卡片文案必须从 `待同步绑定 N` 升级为 `已保存绑定 N`
3. `覆盖集数` 必须从推断态 `1*` 收敛为正式态 `1`
4. 删除临时参考图后，正式沉淀下来的资产 `shot_ids` 绑定不能被一起误删
5. 人物侧 `shot_ids` 解析必须兼容复合键，避免后续多版本定妆被格式差异破坏
