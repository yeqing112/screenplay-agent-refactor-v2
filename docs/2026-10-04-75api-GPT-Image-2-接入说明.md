# 75API GPT Image 2 接入说明

## 已接入模型

模型管理新增独立 provider：`75api-image`。

允许的模型名只有：

- `gpt-image-2-1k`
- `gpt-image-2-2k`

默认 Base URL：`https://www.75api.com`

生图请求使用 OpenAI 兼容路径：

```text
POST /v1/images/generations
Authorization: Bearer <API_KEY>
```

## 模型管理使用

在模型管理中新增 **Image** 配置，Provider 选择 `75api-image`。界面会自动填充 Base URL、默认模型 `gpt-image-2-1k` 和安全默认参数；将模型名改为 `gpt-image-2-2k` 即可配置 2K profile。

连接测试只读取：

```text
GET /v1/models
```

不会提交计费生图任务。API Key 只保存在服务端 profile secret 中，公开模型注册表不会返回明文 Key。

## 当前参数边界

默认按文生图配置：`n=1`、`quality=high`、`response_format=url`，暂不声明参考图、文件上传、负面提示词或异步任务能力。若 75API 后续文档确认这些字段，应该先补 provider contract 和测试，再在模型管理中开启对应能力。
