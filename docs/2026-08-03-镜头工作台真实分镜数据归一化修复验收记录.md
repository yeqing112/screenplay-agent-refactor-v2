# 2026-08-03 镜头工作台真实分镜数据归一化修复验收记录

## 本轮目标

修复正式产品工作台中 `镜头工作台` 误判“当前分集还没有镜头数据”的问题，恢复真实项目分镜列表与镜头详情。

## 根因

真实接口 `/api/pipeline/book/14/outputs` 返回的 `storyboard` 字段为按数字键组织的对象，而不是前端归一化层原先假设的数组。

原实现只兼容：

- `storyboard: StoryboardShotOutput[]`

真实返回则为：

- `storyboard: Record<string, StoryboardShotOutput>`

导致 `normalizeBookOutputs(...)` 将镜头数据归一化为空，进而让镜头工作台显示空列表，而资产中心、创作画布仍能从其他链路看到镜头上下文，形成跨页面不一致。

  - 数组
  - keyed object
