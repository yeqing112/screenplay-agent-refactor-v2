# 2026-07-21 提示词恢复验收样本补充任务与验收标准

## 背景

当前“提示词跑偏 -> 推荐恢复 -> 任务中心直达镜头”的能力已经在代码和测试中成立，但真实项目数据不保证始终保留一个正处于跑偏状态、且仍有可恢复历史版本的镜头。

这会导致真浏览器验收无法稳定复现。

因此新增一条正式补充任务：为提示词恢复链路提供可重复的验收样本工具。

## 可执行任务

### 任务 1：补充提示词恢复验收样本脚本

新增：

- `scripts/storyboard_prompt_recovery_fixture.py`

脚本要求支持三类动作：

1. `status`
2. `degrade`
3. `restore`

### 任务 2：沉淀使用手册

新增：

- `docs/2026-07-21-提示词恢复验收样本脚本与使用说明.md`

文档要求说明：

1. 何时使用脚本
2. 如何制造“当前版本跑偏、历史版本可恢复”的样本
3. 如何恢复
4. 如何保留快照和验收记录

### 任务 3：将规则纳入执行约束

后续所有涉及以下链路的验收：

- `提示词跑偏`
- `推荐恢复版本`
- `任务中心恢复镜头`

都应优先使用正式样本工具，而不是依赖偶发历史数据。

## 验收标准

1. 项目内存在正式脚本，可对指定 `book / episode / shot` 执行 `status / degrade / restore`
2. `degrade` 后可得到一个新的当前版本，并产生可识别的跑偏审计结果
3. 若历史版本健康，则脚本能产出可恢复目标
4. 脚本在执行 `degrade` 与 `restore` 前会落快照文件
5. 项目内存在独立使用手册，可指导后续浏览器验收执行

## 推荐验收路径

1. 对目标镜头先执行一次正常提示词编译
2. 运行：

```bash
python scripts/storyboard_prompt_recovery_fixture.py degrade --book-id 14 --episode 1 --shot-id 1
```

3. 打开正式工作台中的 `任务中心`
4. 确认出现提示词恢复任务
5. 从任务中心跳转到首个恢复镜头
6. 执行推荐恢复
7. 再次运行：

```bash
python scripts/storyboard_prompt_recovery_fixture.py status --book-id 14 --episode 1 --shot-id 1
```

8. 确认当前状态已恢复，或已产生新的回滚版本记录
