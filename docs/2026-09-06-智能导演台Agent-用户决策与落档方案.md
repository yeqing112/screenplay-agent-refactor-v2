## 一、用户决策（已确认）

1. **形态**：右侧抽屉式对话窗口，可隐藏，不影响工作台。
2. **模型**：Agent 使用独立配置的大模型，在「模型管理 → 管理员配置」中单独指定与计费。
3. **显式确认门槛**：
   - 创作预览类、解释与诊断：不需确认，可直接执行。
   - 资产改动、生成任务提交、版本覆盖：必须由用户显式确认。
4. **Skill**：首批内置 TVC、儿童教育、短剧、连续性；并允许第三方或自研扩展。
5. **审计与回放**：所有 Agent 操作纳入审计日志，支持回放。

## 二、产品定位

- 智能导演台不是聊天机器人，而是**受控导演编排 Agent**。
- 职责：理解创作意图 → 盘点当前事实 → 提出可执行计划 → 调度既有工作流 → 发现质量风险 → 在涉及费用、覆盖版本、对外提交或不可逆变更前暂停等待确认。
- 不替代用户创作判断；不绕过现有版本、证据、锁定资产、验收门槛。

## 三、目标架构

        ↓

        ↓

        ↓

        ↓

        ↓
版本、任务、验收、来源记录与 Agent 审计日志
\\\

### DirectorPlan 是一等对象

每次对话先产出一份可查看、可编辑、可恢复的计划，包含：

- objective：用户目标与创作约束
- scope：书 / 集 / 镜头 / 资产范围
- vidence_snapshot：资产、版本、QA、模型能力、预算快照
- steps：只读诊断、草案生成、待确认外部调用、写入、验收
- preconditions / locking_issues：缺图、资产未锁定、Prompt 过期、模型不支持等
- pproval_policy：自动执行 vs 必须确认
- cost_envelope：模型、次数、预计图片/秒数，超出即停止
- ollback_anchor：将影响的版本与可恢复点

### 工具权限分四档

| 档位 | 示例 | Agent 行为 |
|---|---|---|
| A：只读 | 审查剧本、诊断连续性、生成证据包 | 自动执行 |
| B：可逆内部草案 | 修复建议、Prompt 候选、拆镜方案 | 自动保存为草案，不生效 |
| C：版本化写入 | 确认资产治理、创建 Prompt Version、采纳分镜 | 证据未变化且用户确认后执行 |
| D：外部成本/不可逆 | 调 LLM、生成图/视频、上传第三方、删除 | 逐次确认 |

Agent 只能调用权限更低或相等的操作，不能因"智能"获得更高权限。

## 四、Skill 规范

\\\yaml
id: tvc-production-v1
name: TVC 创作与生产
version: 1.0.0
intent_patterns: [\"做一支广告片\", \"创作 TVC\"]
input_schema: brief + audience + product + duration + channels
required_evidence: [brand_constraints, legal_notes, target_platform]
allowed_tools: [script_plan, storyboard_plan, prompt_draft, qa_read]
external_tools: [image_generation, video_generation]
approval_policy:
  image_generation: explicit_each_batch
  video_generation: explicit_each_submit
quality_gates: [brand_safety, claim_check, shot_executability]
outputs: [creative_brief, beat_sheet, storyboard_plan, production_plan]
rollback: versioned_outputs_only
\\\

首批 4 个 Skill：

1. 短剧生产 Skill：承接当前全链路
2. TVC Skill：Brief、卖点、时长、品牌禁忌、平台规格、镜头节奏
3. 儿童教育 Skill：年龄段、知识目标、安全、语言难度、互动节奏
4. 连续性 Skill：相邻镜头连续性诊断与衔接建议

每个 Skill 仅输出结构化计划与草案，复用既有资产、分镜、Prompt、生成、QA 工具，不复制独立数据表或前端。

## 五、模型配置

- Agent 模型与生产链路 LLM 解耦。
- 在「模型管理 → 管理员配置」中独立设置 gentModel：
  - 名称、Base URL、API Key、模型名、是否启用思考、温度、最大输出 Token、并发上限、计费档。
- Agent 自身调用经 LLM 网关，密钥不向 UI 暴露；不允许直接修改生产链路默认模型。
- Agent 模型切换、密钥更新、并发/计费调整均需审计。

## 六、对话 UI

- 全局悬浮按钮（右下角），点击后右侧抽屉展开，覆盖工作台。
- 抽屉三栏：
  1. 会话与历史
  2. 计划 / 草案 / 证据引用
  3. 输入与确认
- 抽屉可关闭、收边、置顶。
- 抽屉与工作台双向联动：
  - 工作台选中对象可作为上下文注入对话
  - 对话中确认的操作在原页面回显

## 七、审计与回放

- 所有 Agent 操作记录至 gent_audit_log：
  - 时间戳、用户、Session、Plan ID、Step、参数、证据指纹、结果、确认人。
- 会话内容与计划对象独立持久化，支持回放。
- 审计页面提供按项目、Skill、模型、时间段、风险等级过滤。
- 审计与现有 DecisionPacket、Prompt Version、资产历史对齐，不重复建表。

## 八、阶段化落地

### Phase 0：导演运行时与模拟

- 新增 DirectorPlan、gent_session、gent_audit_log 领域模型。
- 状态机：草案 → 等待确认 → 执行中 → 验收 → 完成或阻塞。
- 仅"产出计划"影子运行，验证计划准确度。

### Phase 1：对话式导演助手（只读 + 草案）

- 全局抽屉 UI。
- 支持查询、解释、证据包、草案生成；不触发任何 C/D 档操作。
- 验收：对话输出必须可链接到具体对象和版本。

### Phase 2：受控编排

- 将既有 API 映射为 A–D 档工具。
- 支持暂停/确认/恢复、成本上限、失败重试、任务时间线。
- C/D 档逐次确认。

### Phase 3：首批 4 个 Skill

- 短剧 / TVC / 儿童教育 / 连续性。
- Skill 注册表、版本化、灰度开关。
- 第三方 Skill 接入：受控清单 + 沙箱。

### Phase 4：来源与交付治理

- 内部 provenance 图谱、导出清单。
- 评估 C2PA / Content Credentials 可行接入。

## 九、与生产灰度、HTTPS 资产域名的关系

- 智能导演台 Agent 的可执行性依赖于既有受控链路，不替代或绕过。
- HTTPS 资产域名、视频模型参数仍由真实灰度验证；Agent 只能使用已经验证通过的资产与模型。
- 生产链路放行（公网资产域名 + 真实媒体灰度）继续保留，Agent 接入以它为基础。
