# 2026-08-22 单一正式工作台收敛验收记录

## 背景

项目此前同时保留正式工作台、旧版生产、创作沙盘、高级编排和产品原型 Demo。多入口已经不再服务真实用户主路径，反而持续增加维护成本和误入风险。

本轮目标是只保留正式工作台，并在删除旧入口前迁移少数仍有生产价值的能力。

## 本轮变更

- `CanvasPage` 只加载正式工作台。
- 项目列表删除 `产品原型 Demo` 入口。
- 正式工作台侧栏删除旧版生产、创作沙盘、高级编排跳转按钮。
- QA 修复页新增：
  - 修复方案选择与人工修复片段编辑
  - diff 预览
  - 应用修复并复检
  - 脚本修复版本回滚
- 镜头工作台新增：
  - 提示词锁定与解除锁定
  - 验收记录提交
- 正式工作台共享数据迁移到正式目录：
  - `web/src/domain/bookOutputs.ts`
  - `web/src/hooks/useBookOutputs.ts`
  - `web/src/services/modelRegistry.ts`
- 删除旧前端控制台、原型页、节点编排组件与对应测试。

## 保留边界

- 本轮不删除 `/api/prototyping/*`，因为正式工作台仍使用创意任务、参考图生成、任务 reconcile/restart 接口。
- 本轮不删除 `/api/workflows*`、`/api/nodes*`、`/api/runs*` 和历史执行数据；这些放入后续后端专项审计。
- 本轮不删除历史 workflow/run/task 数据。

```powershell
npm test
npm run build
cd ..
npm run e2e:smoke
npm run e2e:qa
python -m unittest tests.test_qa_workbench_flow tests.test_storyboard_prompt_compile tests.test_storyboard_acceptance_feedback

```

- `npm test`：43 个测试文件，221 项测试通过。
- `npm run build`：通过。
- `npm run e2e:smoke`：通过。

- 后端 QA/分镜相关专项：28 项测试通过。
- `git diff --check`：通过，仅出现 Windows 换行提示。
- 构建产物未出现 `ProductionMode`、`DirectorMode`、`SceneComposer`、`NodePanel`、`NodeConfigPanel` 旧工作台 chunk。
