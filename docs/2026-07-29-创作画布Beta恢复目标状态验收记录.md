# 2026-07-29 创作画布 Beta 恢复目标状态验收记录

## 本轮目标

继续补强 `任务中心 -> 创作画布 Beta` 的恢复链路解释能力。

在上一轮里，恢复横幅已经支持：

1. 显示恢复上下文
2. 回任务中心
3. 前往镜头工作台
4. 一键重新定位恢复节点

但仍缺少一个更明确的说明：当前恢复目标到底是

- 正在等待同步
- 已经成功定位
- 还是暂未定位到

本轮目标就是把这层状态语义补齐。

## 本轮实现

涉及文件：

- `web/src/components/productWorkspaceCanvasBeta.ts`
- `web/src/components/ProductWorkspaceCanvasBetaSection.tsx`
- `web/src/components/productWorkspaceCanvasBeta.test.ts`

关键改动：

1. 新增 `buildCanvasNavigationTargetStatus`
   - 统一生成恢复目标状态
   - 支持三种状态：
     - `syncing`
     - `resolved`
     - `missing`

2. 在 `恢复上下文` 横幅内新增状态提示区
   - `正在等待目标节点`
   - `已定位到恢复目标`
   - `暂未定位到恢复目标`

3. 每种状态都有对应解释文案，减少用户猜测：
   - 同步中：说明画布仍在同步真实项目数据
   - 已定位：说明当前已经接住恢复目标，可继续围绕镜头或资产推进
   - 未定位：说明上下文仍保留，但目标节点暂未出现在画布中，建议回任务中心或镜头工作台继续确认
