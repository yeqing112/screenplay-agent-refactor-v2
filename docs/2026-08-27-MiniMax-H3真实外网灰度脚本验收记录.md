# 2026-08-27 MiniMax H3 真实外网灰度脚本验收记录

## 结论

本轮已新增 MiniMax H3 真实账号灰度脚本第一版。

该脚本的核心目标不是直接跑真实视频，而是把“能否安全跑第一个真实样本”变成可审计的预检报告和强门禁 SOP。

## 新增入口

- 脚本：`scripts/validate-minimax-h3-gray.py`
- npm 命令：`npm run validate:minimax-h3-gray`

默认用法：

```powershell
npm run validate:minimax-h3-gray -- 75 1 1
```

自动选择候选镜头：

```powershell
npm run validate:minimax-h3-gray -- auto
```

自动候选会优先选择：

- 已有采纳首帧
- 首帧是外部可访问 URL
- 尽量没有既有视频版本
- H3 prompt 不含高风险坠落 / 伤害动作
- H3 prompt 尽量不含 `画面开场 / 画面切 / 请生成` 等遗留导演切口标记

该命令只做 dry-run：

- 读取真实 `book / episode / shot`
- 调用只读机器提示词导出 API
- 抽取 MiniMax H3 `integrated_multimodal_description`
- 检查 prompt 长度、首帧、视频模型配置、API key readiness
- 写出 `artifacts/minimax-h3-gray-*.json|md`
- 不登记任务
- 不提交 MiniMax
- 不写回视频资产

## 真实提交门禁

真实模式必须同时满足：

- CLI 显式参数：`--allow-real`
- 环境变量：`MINIMAX_H3_GRAY_REAL=1`
- 环境变量：`MINIMAX_H3_GRAY_CONFIRM=CONFIRM_MINIMAX_H3_SUBMIT`
- 环境变量：`MINIMAX_H3_GRAY_WHITELIST` 精确包含目标，例如 `75:1:1`
- 当前默认视频模型或显式 `--model-profile-id` 必须是 `minimax-h3-async`
- metaso MiniMax H3 兼容 API base URL 与 API Key 必须配置完成：`https://metaso.cn/api/minimax` + `mk-...`
- H3 prompt 不为空且不超过 7000 字

真实模式走正式后端链路：

1. `POST /api/books/{book_id}/storyboard/{episode}/{shot_id}/machine-prompt-api-submissions`
2. `POST /api/prototyping/tasks/{task_id}/submit-machine-prompt-provider`
3. `GET /api/prototyping/tasks/{task_id}`

因此真实灰度能同时验证：

- 机器提示词导出
- API 提交登记
- MiniMax H3 provider submit
- provider polling
- 视频资产回写
- 任务中心可追踪状态
