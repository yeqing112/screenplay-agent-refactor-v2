# 2026-08-27 导出资产库后端查询分页验收记录

## 背景

项目级导出资产库第一版已经能在正式工作台统一展示交付包、阻塞快照和机器提示词导出快照，但第一版仍通过 `/api/books/{book_id}/export-records` 全量读取记录。随着真实项目记录增加，全量读取会让资产库、镜头导出历史和后续 WebUI 草稿恢复链路变重。

## 本轮改动

- `GET /api/books/{book_id}/export-records` 新增兼容查询参数：
  - `record_type`
  - `episode`
  - `status`
  - `format`
  - `query`
  - `limit`
  - `offset`
- 返回体新增分页元信息：
  - `total`
  - `limit`
  - `offset`
  - `returned`
  - `has_more`
  - `filters`
- `record_type` 支持两类用法：
  - 精确记录类型：`storyboard_machine_prompt_export`
  - 资产类型别名：`machine_prompt` / `delivery_package`
- `format` 同时兼容原始格式和展示标签，例如 `delivery` / `交付快照`。
- `query` 采用多关键词 AND 检索，可命中摘要、格式、状态、场景名、镜头号、目标模型、导出通道、导演分镜语言和阻塞原因。
- 修正后端 `delivery` 格式标签历史乱码，统一返回 `交付快照`。
- 前端读取点接入新能力：
  - 导出资产库默认读取最近 500 条，避免无边界全量拉取。
  - 镜头工作台机器提示词历史先按 `record_type=storyboard_machine_prompt_export` 和当前集数在后端缩小范围，再由前端精确筛当前镜头。

## 当前边界

- 后端已经支持分页元信息，但正式工作台资产库 UI 暂未做“加载更多 / 翻页”控件；当前先通过 `limit=500` 限制首批读取。
- 暂未新增 `shot_id` 精确查询参数；镜头工作台目前用后端 `record_type + episode` 缩小范围后，在前端按镜头精确过滤。
- 机器提示词历史快照恢复为 WebUI 临时草稿已在后续批次完成，见 `docs/2026-08-27-机器提示词历史快照恢复草稿验收记录.md`。

## 后续建议

1. 在项目级导出资产库 UI 增加“加载更多”或分页游标，消费 `has_more / offset / limit`。
2. 增加 `shot_id` 查询参数，进一步优化单镜头机器提示词历史读取。
3. 继续支持导出草稿人工临时修改边界和 API 提交独立任务链路。
