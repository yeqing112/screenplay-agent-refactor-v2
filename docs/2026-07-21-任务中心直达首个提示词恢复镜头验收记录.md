# 2026-07-21 任务中心直达首个提示词恢复镜头验收记录

## 本次目标

把任务中心中的提示词跑偏任务，从“回镜头工作台查看”推进成“直接落到首个推荐恢复镜头”。

## 本次实现

### 1. 任务中心恢复目标推导

文件：

- `web/src/components/productWorkspaceTaskCenterState.ts`

新增：

- `inferEpisodeFromTask(...)`

增强：

- `inferShotIdFromTask(...)`

规则：

1. 若任务本身已有 `shotId`，优先使用
2. 若任务带有 `promptHealth.degradedShots`
   - 优先选择带 `recommendedRestoreVersion` 的镜头
   - 否则退回到第一条跑偏镜头
3. 同时推导对应的 `episode`

### 2. 任务中心导航改为传递推导后的 episode / shotId

文件：

- `web/src/components/ProductWorkspaceTasksSection.tsx`
- `web/src/components/productWorkspaceTaskCenterSelectedTaskPanel.tsx`

调整：

- 任务列表点击
- 任务详情主操作按钮点击

现在都会优先使用：

- `inferEpisodeFromTask(...)`
- `inferShotIdFromTask(...)`

因此批量提示词恢复任务不再只跳到镜头工作台首页，而是可直接定位到首个推荐恢复镜头。

### 3. 按钮文案同步收口

文件：

- `web/src/components/productWorkspaceTasks.ts`

调整：

- 当提示词恢复任务存在推荐恢复版本时
- `actionLabel` 改为 `前往首个恢复镜头`

## 验收标准

满足以下条件视为通过：

1. 批量提示词恢复任务可以推导出首个推荐恢复镜头
2. 如果没有推荐恢复版本，也能退回到第一条跑偏镜头
3. 任务列表点击与详情主按钮点击都使用同一套推导逻辑
4. 前端测试与构建通过
