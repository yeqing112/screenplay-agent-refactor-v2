# 旧节点接口生产收口审计

日期：2026-08-30

## 结论

正式 React 工作台没有调用以下旧 DevCanvas 节点接口：

- `/api/workflows*`
- `/api/nodes/registry`
- `/api/nodes/run*`
- `/api/runs*`

这些接口仍可创建工作流文件、启动旧节点执行器、读取或重放运行快照；它们不属于正式工作台的生产主链路。

## 已实施的兼容收口

- 增加 `ENABLE_LEGACY_NODE_API` 配置，默认 `true`，不影响既有本地用户。
- 设置为 `false` 后，上述路径统一返回 `410 Gone`，并提示迁移至正式工作台 API。
- 该开关由 HTTP 中间件执行，正式工作台接口与 `/health` 不受影响。

## 上线操作

在生产环境 `.env` 中设置：

```env
ENABLE_LEGACY_NODE_API=false
API_CORS_ORIGINS=https://your-frontend.example.com
API_CORS_ALLOW_CREDENTIALS=false
```

在确认没有外部旧客户端依赖后启用。此开关只收口旧接口，不替代认证、HTTPS、密钥轮换或数据库备份。

## 验证

- `tests/test_api_security.py` 覆盖禁用后返回 `410`，同时验证正式健康检查仍为 `200`。
- `npm --prefix web run build` 通过。
