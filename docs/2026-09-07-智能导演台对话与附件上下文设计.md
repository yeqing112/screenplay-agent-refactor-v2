# 智能导演台：对话与附件上下文

智能导演台面向普通创作者时，应表现为右侧可收起的对话助手，而不是工具配置面板。用户可以输入自然语言，并附上图片、创作简报、剧本片段或参考文档；技能与工具分级由系统在后台编排。

## 已落地的最小闭环

- 对话输入区支持 PNG、JPG、WEBP、TXT、MD、PDF、DOCX，每轮最多 6 个附件。
- 附件存放在项目私有目录，不会自动公开到对象存储，也不会自动成为生图或生视频参考。
- 文档仅提取有上限的文本作为**不可信参考材料**：其内容不能覆盖锁定资产、冻结证据、系统规则或用户确认门槛。
- 图片保留私有原件与 SHA-256。只有 Agent 模型配置的 `default_params.supports_vision=true` 时，用户在预览后确认的真实调用才会以视觉资料传给 OpenAI-compatible 模型；否则界面必须明确告知“未识图”。
- 附件元数据和指纹进入冻结证据包；提取出的原文不写入 Agent 审计/计划记录。真实模型调用仍需要 `confirmed=true` 与 `allowExternalCall=true`。

## 交互边界

1. 上传附件、生成只读计划：不调用外部 LLM，不改生产内容。
2. 查看 AI 分析预览：展示当前模型、将发送的资料类型和计费提示，仍不调用外部 LLM。
3. 用户确认“生成 AI 建议”：才可将文档摘录和（若模型已声明支持）图片送至外部模型；结果只能保存为候选建议。
4. 改资产、改脚本、写 Prompt Version、图片/视频生成继续使用各自已有的证据、差异、版本与双确认流程。

## 后续迭代

- 将每条用户消息、助手回复和确认卡持久化为真正的多轮会话，而不是仅回放候选草案。
- 在模型管理中把“支持识图”做成可理解的明确能力开关，并在连接测试中验证供应商接受视觉消息。
- 为 PDF 扫描件补充可选 OCR；在未配置 OCR 时明确提示“未提取到可读文字”。
- 增加附件到期/保留策略与项目级下载权限，保持审计可复现与资料最小暴露。
