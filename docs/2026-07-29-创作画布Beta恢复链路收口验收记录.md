# 2026-07-29 创作画布 Beta 恢复链路收口验收记录

## 本轮目标

继续补强 `任务中心 -> 创作画布 Beta` 的恢复链路闭环能力。

在上一轮里，恢复横幅已经能说明：

1. 当前恢复目标是否已定位
2. 是否可以重新定位恢复节点
3. 是否可以回任务中心或前往镜头工作台

但还缺少一个关键判断：

- 这条恢复链路现在到底还要不要继续盯
- 还是说结果已经回写，已经可以离开恢复流程，继续正常创作

本轮目标就是把“恢复是否已收口”显式做出来。

## 本轮实现

涉及文件：

- `web/src/components/productWorkspaceCanvasBeta.ts`
- `web/src/components/ProductWorkspaceCanvasBetaSection.tsx`
- `web/src/components/productWorkspaceCanvasBeta.test.ts`

关键改动：

1. 新增 `buildCanvasRecoveryClosureStatus`
   - 统一根据当前恢复上下文与运行态生成恢复链路收口状态

2. 当前支持的恢复收口状态包括：
   - `恢复收口同步中`
   - `恢复结果仍待回收`
   - `恢复链路已收口`
   - `恢复目标已变化`
   - `恢复收口待人工确认`

3. 判断逻辑不依赖猜测，而是直接基于当前已有运行态：
   - 本地 pending recovery task
   - 镜头 latest execution summary
   - 是否已有编译结果
   - 是否已有已采纳首帧
   - 是否已有已采纳视频
   - 是否已有结构化参考图

4. 当恢复链路已经收口时，横幅会明确提示：
   - `恢复链路已收口`
   - 可继续在镜头、资产或分镜产物侧推进后续创作
   - 不必继续停留在恢复流程里
