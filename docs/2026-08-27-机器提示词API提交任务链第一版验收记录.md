# 2026-08-27 机器提示词 API 提交任务链第一版验收记录

## 结论

本轮已完成机器提示词 API 提交任务链第一版。

该版本只负责把正式工作台当前机器提示词导出快照登记为任务中心任务，不调用真实模型 provider，不产生真实外部提交。

关键边界：

- 默认机器提示词导出仍是 `API 未提交 / 仅导出`。
- 用户必须显式点击“登记 API 提交任务”才会创建任务。
- 新任务类型为 `machine_prompt_api_submission`。
- 任务会进入任务中心，可追踪、可恢复、可审计。
- 第一版任务字段明确 `api_submission = true`，但 `actual_provider_submission = false`。
- provider 标记为 `pending-generation-adapter`，外部状态为 `waiting_for_generation_adapter`。

## 已完成实现

- 新增后端接口：
  - `POST /api/books/{book_id}/storyboard/{episode}/{shot_id}/machine-prompt-api-submissions`
- 新增请求模型：
  - `StoryboardMachinePromptApiSubmissionRequest`
- 新增持久化任务类型：
  - `creative-machine_prompt_api_submission`
- 任务中心列表已能读取持久化和运行时的 `machine_prompt_api_submission`。
- 正式镜头工作台机器提示词导出面板新增“登记 API 提交任务”按钮。
- 任务中心数据层将该任务识别为提示词类任务，不再 fallback 为视频任务。
- `npm run e2e:machine-prompt-export` 已扩展为真实浏览器验证：
  - 加载机器提示词预览
  - 编辑导演分镜语言

  - 恢复系统版
  - 登记 API 提交任务
